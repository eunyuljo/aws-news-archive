# AWS Marketplace agent mode now helps you assess, buy, and deploy solutions

**날짜:** 2026년 11월 20일
**서비스:** SystemsManager
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/aws-marketplace/aws-marketplace-agent-mode-expansion

## 내용

You can now assess a seller's security, buy, and deploy supported products in one conversation with AWS Marketplace agent mode, the conversational AI experience for procuring cloud solutions. You share your requirement once, and agent mode applies them as it guides you through discovery, purchase, and deployment. 
Describe your use case in natural language to get recommended software, services, AI agents and tools, and multi-product solutions that fit your business needs. To assess a seller's security, request documents such as System and Organization Controls (SOC) 2 reports, and get a criterion-by-criterion assessment against a standard cloud security questionnaire, the Consensus Assessments Initiative Questionnaire (CAIQ). 
When you're ready to buy, sign in with your AWS account. Agent mode explains pricing and terms so you know what you're committing to, shows your organizations' purchase requirements, and completes the purchase after you review the terms and confirm. For supported products, agent mode reviews your AWS environment, proposes a deployment plan with the estimated monthly cost, and deploys after you approve. It then shows you how to start using the product and helps you troubleshoot if a step fails. 
Agent mode is available in all AWS Regions where AWS Marketplace is available. 
To get started, open agent mode on the AWS Marketplace website. To learn more, see Agent mode for AWS Marketplace in the AWS Marketplace Buyer Guide.
