# AWS Transform automates source and migration target actions to accelerate cutover

**날짜:** 2026년 11월 19일
**서비스:** Config
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/aws-transform-automates-source-actions/

## 내용

AWS Transform now automates the tasks that prepare and validate your servers during a migration, before they move and after they launch on AWS. AWS Transform is the agentic AI service that speeds up cloud migration, application modernization, and continuous tech debt reduction. With the new source actions capability, you can create actions and run them securely on your source servers at the right point in the migration, from the early stages through cutover. Post-launch actions complement this by automatically configuring and validating each workload as soon as it launches on AWS. 
Cutover preparation and validation are often manual, time-consuming tasks in large-scale migrations. Traditionally, migration teams log in to each source server to stop services and freeze database writes before shutdown, and then check connectivity, application health, and monitoring on each server after it launches. 
With source actions in AWS Transform, you define each action once, run it in bulk on the servers and waves you choose, and reuse it across accounts and migrations. AWS Transform manages these actions centrally, so you can reuse them across accounts and migrations instead of rebuilding them each time. You can monitor the status of each action and confirm your go/no-go decision before moving to the next step. Source preparation and post-launch actions are now part of the migration plan itself, so you no longer have to coordinate and run these activities by hand. 
This capability is available in all AWS Regions where AWS Transform for migrations is available. To get started, see the AWS Transform documentation or visit the AWS Transform product page.
