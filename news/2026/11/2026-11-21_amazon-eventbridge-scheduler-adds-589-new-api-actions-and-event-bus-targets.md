# Amazon EventBridge Scheduler adds 589 new API actions and event bus targets

**날짜:** 2026년 11월 21일
**서비스:** EventBridge
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/eventbridge-scheduler-new-api-actions/

## 내용

Amazon EventBridge Scheduler expands its AWS SDK integrations with 589 new API actions across 81 AWS services, and adds templated targets for the enhanced EventBridge Custom event bus. You can now schedule direct invocations of a broader set of AWS services without writing custom integration code. 
EventBridge Scheduler is a serverless scheduler that allows you to create, run, and manage billions of scheduled events and tasks across more than 270 AWS services, without provisioning or managing the underlying infrastructure. With a new templated target, you can schedule event delivery directly to the Custom event bus using its PutEvents or PutRawEvents API. The templated target also makes it easier to add metadata fields to each event. For example, you can send an event to your bus every night at midnight to start a reconciliation workflow, with no function in between to call the API. 
The new API actions are available in all commercial AWS Regions where Amazon EventBridge Scheduler is available, subject to the availability of each target service in the Region. The templated targets for the Custom event bus are available in all AWS Regions where the enhanced Custom event bus is available. To learn more, see Using templated targets in EventBridge Scheduler and Using universal targets in EventBridge Scheduler in the Amazon EventBridge Scheduler User Guide.
