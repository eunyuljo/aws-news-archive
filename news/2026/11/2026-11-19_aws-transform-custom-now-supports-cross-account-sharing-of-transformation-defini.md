# AWS Transform custom now supports cross-account sharing of transformation definitions

**날짜:** 2026년 11월 19일
**서비스:** General
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/aws-custom-cross-account-td/

## 내용

AWS Transform custom now enables you to share transformation definitions (TDs) and their associated lessons across AWS accounts, organizational units (OUs), or your entire organization in AWS Organizations through AWS Resource Access Manager (AWS RAM). AWS Transform custom is a capability of AWS Transform that performs transformations across your technology stack, including API and framework upgrades, migrations, and language translations. 
With this launch, you can share TDs as live resources rather than static copies, so consumers run the owner's latest published version by default while the owner maintains full control. As the TD owner, you select from four managed permissions ranging from execute-only (the default) to permissions that allow consumers to use your lessons, contribute lessons back to you, or download the TD. Lessons flow back to the owner only when the permission allows it and the consumer opts in. 
This capability is particularly valuable for platform engineering teams and AWS Partners who need to deploy standardized transformations across multiple accounts. A central team can create a TD once and share it organization-wide. 
This feature is available via the AWS Transform CLI and AWS RAM in US East (N. Virginia), Europe (Frankfurt), Europe (London), Asia Pacific (Mumbai), Asia Pacific (Seoul), Asia Pacific (Sydney), Asia Pacific (Tokyo), and Canada (Central) Regions. To learn more, visit the AWS Transform User Guide.
