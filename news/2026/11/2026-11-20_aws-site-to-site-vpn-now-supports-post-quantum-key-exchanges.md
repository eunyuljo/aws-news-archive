# AWS Site-to-Site VPN now supports post-quantum key exchanges

**날짜:** 2026년 11월 20일
**서비스:** Config
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/site-to-site-vpn-post-quantum/

## 내용

AWS Site-to-Site VPN now supports post-quantum key exchanges to help improve the security posture of your VPN tunnels. This feature supports your migration to post-quantum cryptography based on NIST guidelines.  AWS Site-to-Site VPN is a fully managed service that creates an encrypted connection between your data center or branch office and your AWS resources using IPsec tunnels. With AWS Site-to-Site VPN, you can now configure post-quantum key exchange methods in your VPN tunnel options using the CreateVpnConnection and ModifyVpnTunnelOptions APIs.  There is no additional charge for using post-quantum key exchanges. This capability is available in all AWS commercial Regions and AWS GovCloud (US) Regions where AWS Site-to-Site VPN is available. To learn more, visit the AWS Site-to-Site VPN documentation.
