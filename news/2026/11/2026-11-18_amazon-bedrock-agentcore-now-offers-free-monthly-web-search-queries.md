# Amazon Bedrock AgentCore now offers free monthly web search queries

**날짜:** 2026년 11월 18일
**서비스:** Bedrock
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/bedrock-agentcore-free-web-search-queries/

## 내용

Amazon Bedrock AgentCore now offers 5,000 free web search queries per month through the Web Search Tool in AgentCore gateway and the Web Search API. AgentCore helps developers build, deploy, and operate highly effective agents securely at scale. Developers can now build and test agents with web search capabilities at no cost for their first 5,000 queries each month. 
The free allowance applies automatically, with no setup required. It is shared across supported AWS Regions and by all accounts in an organization, and resets each month. Additional queries are billed at standard rates without interrupting your agents. 
Free web search queries are available in all AWS Regions that support the Web Search Tool and Web Search API: US East (N. Virginia), US East (Ohio), US West (Oregon), Europe (Ireland), Asia Pacific (Sydney), and Asia Pacific (Tokyo). 
To learn more, see AgentCore pricing,&nbsp;Web Search Tool in the AgentCore Developer Guide, and the AgentCore product page.
