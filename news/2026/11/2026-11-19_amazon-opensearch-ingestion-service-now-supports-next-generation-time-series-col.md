# Amazon OpenSearch Ingestion Service now supports next-generation time series collections

**날짜:** 2026년 11월 19일
**서비스:** S3
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-opensearch-ingestion-service-nextgen-time-series-collections

## 내용

Amazon OpenSearch Ingestion service now supports time series collections in the next generation of Amazon OpenSearch Serverless as a pipeline destination. You can stream logs, metrics, traces and event data into time series collections with fully managed pipelines. You don't have to run your own collectors or write custom ingestion code. 
OpenSearch Ingestion delivers data from the sources you already use, including OpenTelemetry, Amazon S3, Amazon Kinesis Data Streams, Amazon MSK, Amazon DynamoDB, and HTTP endpoints. Before indexing, pipelines can filter, enrich, transform, and route data with built-in processors. For example, you can parse and normalize log fields, mask sensitive data, or split a stream into separate indexes. Pipelines scale automatically with your workload. Time series collections add a lower-cost warm storage tier and built-in alerting and anomaly detection. Together they give you an observability pipeline from collection to analysis with no clusters to manage. 
To get started, create a pipeline in the Amazon OpenSearch Service console, through the AWS CLI, or with AWS CloudFormation, and choose a time series collection as the sink. OpenSearch Ingestion is billed in Ingestion OpenSearch Compute Units (OCUs), separately from your collection. For details, see Amazon OpenSearch Service pricing. 
This capability is available in all AWS Regions where both Amazon OpenSearch Ingestion and the next generation of Amazon OpenSearch Serverless are available. To get started, create a pipeline in the Amazon OpenSearch Service console, through the AWS CLI, or with AWS CloudFormation, and choose a next-generation time series collection as the sink. To learn more, see Overview of Amazon OpenSearch Ingestion in the Amazon OpenSearch Service Developer Guide.
