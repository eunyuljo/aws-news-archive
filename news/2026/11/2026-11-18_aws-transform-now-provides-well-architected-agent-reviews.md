# AWS Transform now provides Well-Architected Agent reviews

**날짜:** 2026년 11월 18일
**서비스:** VPC
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/transform-well-architected-agent/

## 내용

AWS Transform for migrations now includes Well-Architected reviews of target networks as it migrates and modernizes infrastructure to AWS. These recommendations, provided by the AWS Well-Architected Agent in public preview, are based on the latest best practices across security, reliability, and cost optimization pillars, and are applied directly to your target network, so you don't have to update the infrastructure after deployment on AWS.
While migrating networks, design gaps typically surface after deployment, making fixes costly, requiring separate review and update cycles. For teams migrating large on-premises networks, this capability catches improvement opportunities early in the planning stage. AWS Well-Architected Agent provides recommendations, such as re-addressing spoke VPCs using non-RFC1918 addresses and governing CIDR allocation, and AWS Transform applies them to the network design. Post-deployment recommendations are documented for you as downloadable artifact from AWS Transform chat, so you can address them in your AWS accounts once your network is live.
The capability is available in commercial AWS Regions. Well-Architected Agent is delivered by AWS Support and included with paid Support plans.
To get started, see AWS Transform for migrations. To learn more about AWS Well-Architected Agent, visit the product documentation.
