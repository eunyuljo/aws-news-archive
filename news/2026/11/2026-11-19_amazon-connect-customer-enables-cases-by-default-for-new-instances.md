# Amazon Connect Customer enables Cases by default for new instances

**날짜:** 2026년 11월 19일
**서비스:** EventBridge
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/connect-cases-enabled-by-default/

## 내용

Amazon Connect Customer enables Cases by default for new instances, so operations teams can start tracking and resolving customer issues on day one without any setup work. New instances come with Cases connected to rules for setting SLAs, Customer Profiles for personalizing customer experiences, and Amazon EventBridge for triggering actions in other business applications when a case is updated. 
Administrators of existing instances can enable these integrations with one click in the AWS Management Console. Newly added case fields sync automatically, so admins don't have to update integrations each time they create fields. 
Cases is available in the following AWS Regions: US East (N. Virginia), US West (Oregon), Canada (Central), Europe (Frankfurt), Europe (London), Asia Pacific (Seoul), Asia Pacific (Singapore), Asia Pacific (Sydney), Asia Pacific (Tokyo), and Africa (Cape Town). To learn more and get started, visit the Cases webpage and documentation.
