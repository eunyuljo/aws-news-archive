# AWS Continuum for Penetration Testing now estimates task hours before you run a test

**날짜:** 2026년 11월 21일
**서비스:** General
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/continuum-pentest-cost-estimates/

## 내용

AWS Continuum for Penetration Testing (formerly AWS Security Agent) now lets you estimate task hours before running a penetration test, so developers and security teams can see how many billable task hours a test is likely to need and choose a maximum task-hours limit with confidence. Continuum for Penetration Testing runs on-demand, AI-driven penetration tests against your web applications and APIs. Previously, the only way to know how long a test would take was to run it, making it difficult to plan budgets and set appropriate usage limits.
With task-hour estimates, you open a penetration test, choose the Pentest cost estimate tab, and request an estimate. AWS Continuum runs a short preliminary analysis of your application's scope. It then draws on expertise from past penetration tests to estimate the task hours needed and shows the task hours that most similar applications finish within, and the higher range a few applications require. Requesting an estimate is free, and the estimate is a guide, not a quote or a limit. Actual task hours can be higher or lower, and only the maximum task-hours limit caps usage.
Task-hour estimates are available in all AWS Regions where AWS Continuum for Penetration Testing is available.
To learn more, see the documentation. To get started, visit the AWS Continuum product page.
