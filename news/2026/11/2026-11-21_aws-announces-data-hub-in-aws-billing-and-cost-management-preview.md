# AWS announces Data Hub in AWS Billing and Cost Management (preview)

**날짜:** 2026년 11월 21일
**서비스:** General
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/data-hub-billing-cost-management-preview/

## 내용

Today, AWS announces the preview of Data Hub in AWS Billing and Cost Management, a managed data layer that enables AWS FinOps Agent to query cost and usage data with SQL. In preview, Data Hub is available to AWS FinOps Agent, so the agent can identify the individual resources behind a cost change, break down spend by team or cost allocation tag, and show how a resource's cost and usage change hour by hour. With AWS FinOps Agent and Data Hub, customers get these answers without setting up a data export or building and maintaining a cost data pipeline. 
Data Hub provides 13 months of hourly, resource-level cost and usage data in the published CUR 2.0 schema, including resource identifiers and cost allocation tags. AWS provisions the data, refreshes data daily, and maintains the schema as new services, commitments, and charge types are added. When set up from the management account, Data Hub covers cost and usage data across the accounts in your organization. 
Data Hub (preview) is available in the US East (N. Virginia) Region and covers cost and usage data across regions. There is no charge for Data Hub during preview. 
To learn more about Data Hub, see the AWS Billing and Cost Management User Guide and the launch blog. You can get started from the Data Hub page in the AWS Billing and Cost Management console or from the AWS FinOps Agent console.
