# Amazon EC2 and VPC now display related resources for all resource types

**날짜:** 2026년 11월 05일
**서비스:** EC2
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/ec2-vpc-related-resources-all-types/

## 내용

Amazon Elastic Compute Cloud (Amazon EC2), Amazon Virtual Private Cloud (Amazon VPC), and AWS Global View now display related resources for all resource types in their consoles. Previously, only security groups had an option to view related resources. Now you can see relationships for all EC2 and VPC resource types, including EC2 instances, Amazon Elastic Block Store (Amazon EBS) volumes, Launch Templates, Auto Scaling groups, subnets, route tables, and more. The Related Resources tab has also been moved to the console toolbar for easier access.
This capability helps you better understand your infrastructure dependencies and troubleshoot issues more efficiently. For example, when investigating an EC2 instance issue, you can quickly view its associated EBS volumes, security groups, subnets, and route tables without navigating between multiple console pages. Network administrators can now trace connections from a subnet to its associated route tables, network ACLs, and instances, streamlining network configuration reviews and security audits.
This feature is now available in all commercial AWS Regions.
To learn more, visit Amazon EC2 and Amazon VPC in the AWS Management Console.
