# AWS Marketplace now offers Express Checkout for buyers without an AWS account

**날짜:** 2026년 11월 20일
**서비스:** General
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/aws-marketplace-express-checkout/

## 내용

Today, AWS announces AWS Marketplace Express Checkout, a simpler way for businesses that don't have an existing AWS account to buy software from established vendors in AWS Marketplace. 
Express Checkout is built for businesses that don't use AWS today and just want to buy software. With no cloud setup required, buyers sign in with an email address or a social login, pay with a credit or debit card, and check out in a few steps. Businesses that buy multiple applications this way can manage all of their Express Checkout subscriptions in one place, without a separate billing login for each vendor. From there, they can update their card, download invoices, or cancel a subscription themselves. 
For sellers, Express Checkout opens a new segment of self-serve business buyers, using the same listing and AWS Marketplace integration they use today. Sellers with an eligible public SaaS listing can request to add their product to the Express Checkout catalog. 
Express Checkout is available for eligible SaaS products to buyers in the United States and Canada. Businesses that already use AWS can continue to buy in AWS Marketplace with their AWS account. 
To get started, visit the AWS Marketplace Express Checkout page.&nbsp;To learn more, see the&nbsp; AWS Marketplace Buyer Guide and the&nbsp; AWS Marketplace Seller Guide.
