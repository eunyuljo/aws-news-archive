# AWS CodeConnections is now available in the AWS GovCloud (US-West) Region

**날짜:** 2026년 11월 06일
**서비스:** CodeBuild
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/aws-codeconnections-govcloud-west/

## 내용

AWS CodeConnections is now available in the AWS GovCloud (US-West) Region, in addition to AWS GovCloud (US-East). CodeConnections lets you connect AWS services such as AWS CodePipeline and AWS CodeBuild to source code repositories hosted with third-party providers such as Bitbucket.
With this launch, customers running workloads in AWS GovCloud (US-West) can create connections to their source repositories in the same Region as their pipelines. For example, a team can configure a connection so that a commit to their repository automatically starts a release in AWS CodePipeline, without managing provider credentials for each integration.
To learn more, see the AWS CodeConnections User Guide and the AWS GovCloud User Guide. To get started, visit the AWS GovCloud (US) console.
