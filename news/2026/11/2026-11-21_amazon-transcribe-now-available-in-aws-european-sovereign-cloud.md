# Amazon Transcribe now available in AWS European Sovereign Cloud

**날짜:** 2026년 11월 21일
**서비스:** S3
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-transcribe-germany/

## 내용

Amazon Transcribe is now available in the AWS European Sovereign Cloud (Germany) Region. Customers who need to keep data and operations within the EU for regulatory compliance and data sovereignty requirements can now use automatic speech recognition (ASR) in the Region to turn speech into text. 
Amazon Transcribe offers two ways to transcribe audio in this Region. Batch transcription processes media files stored in Amazon S3, and streaming transcription returns text in real time from live audio over HTTP/2 or WebSocket. Both support custom vocabularies, so you can improve recognition of domain-specific terms such as product names, industry jargon, and proper nouns. 
To learn more, see Getting started with Amazon Transcribe, Supported languages and language-specific features, and AWS European Sovereign Cloud pricing.
