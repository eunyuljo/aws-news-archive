# AWS Deadline Cloud now supports Amazon EC2 G7 instances in service-managed fleets

**날짜:** 2026년 11월 19일
**서비스:** EC2
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/deadline-cloud-supports-ec2-g7/

## 내용

AWS Deadline Cloud now supports Amazon EC2 G7 instances in service-managed fleets. Deadline Cloud is a fully managed service that helps teams run compute-intensive workloads for visual effects, animation, product design, simulation, and gaming.
G7 instances give customers more options to scale GPU capacity quickly. You can add G7 instances to your service-managed fleets in sizes from g7.2xlarge to g7.48xlarge, with On-Demand or Spot pricing on Linux or Windows workers. This lets you scale GPU rendering capacity to match your production schedule without managing your own render farm infrastructure.
To get started, create or update a service-managed fleet in the Deadline Cloud console, AWS CLI, or AWS SDKs, and select the RTX PRO 4500 GPU accelerator. G7 instances are available in the US East (N. Virginia), US East (Ohio), US West (Oregon), Europe (Frankfurt), Europe (London), and Asia Pacific (Sydney) Regions. To learn more, see Use a GPU accelerator in the AWS Deadline Cloud User Guide.
