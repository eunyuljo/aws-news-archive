# Kimi K3.1 Pro (Highspeed) now available on Amazon Bedrock

**날짜:** 2026년 11월 07일
**서비스:** Bedrock
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/moonshot-ai-kimi-k3-1-pro-on-amazon-bedrock

## 내용

Today, Kimi K3.1 Pro from Moonshot AI is available on Amazon Bedrock, expanding our open weight model portfolio with the security and governance that customers rely on. Customers using Amazon Bedrock can now run agentic use cases such as coding and document processing on Kimi K3.1 Pro (Highspeed), which delivers high output tokens per second (OTPS) for faster, more responsive results. 
According to Moonshot AI, Kimi K3.1 Pro is an open-weight, natively multimodal agentic model with a 1-million-token context window, and its most capable 3-trillion-parameter-class model to date. Moonshot AI reports improvements in coding, 3D creation, financial research, and other agentic work. On Amazon Bedrock, it runs within the same security boundary as proprietary models and supports explicit prompt caching to reduce latency and input costs. 
Kimi K3.1 Pro is available in all AWS Regions where Amazon Bedrock is available through cross-Region inference. To get started, visit the Amazon Bedrock console. To learn more, see the Amazon Bedrock documentation.
