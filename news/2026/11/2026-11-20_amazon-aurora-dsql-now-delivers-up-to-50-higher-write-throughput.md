# Amazon Aurora DSQL now delivers up to 50% higher write throughput

**날짜:** 2026년 11월 20일
**서비스:** Aurora
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/aurora-dsql-higher-write-throughput/

## 내용

With upgrades to its storage layer, Amazon Aurora DSQL now delivers up to 50% higher write throughput for many transactional workloads. Data loads finish sooner, and tables whose primary key always increases, such as tables keyed by a timestamp, an identity column, or a time-ordered ID like ULID or UUIDv7, see even greater benefits. 
Applications such as audit logs, ledgers, and event feeds are read in time order, and keying them by time keeps those reads fast. You can now use that design for write-heavy tables too. In our tests, an audit log table keyed by event time accepted up to 200% more inserts per second. 
The improvement is available in all AWS Regions where Aurora DSQL is available, for new and existing clusters, at no additional cost. To learn more, see the Aurora DSQL User Guide.
