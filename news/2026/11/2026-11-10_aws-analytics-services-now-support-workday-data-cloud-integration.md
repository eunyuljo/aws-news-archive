# AWS Analytics services now support Workday Data Cloud integration

**날짜:** 2026년 11월 10일
**서비스:** Glue
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/aws-analytics-workday-data-cloud/

## 내용

Today, AWS announces a new bi-directional, zero-copy integration between AWS Analytics services and Workday Data Cloud. Instead of building and maintaining ETL pipelines to replicate data between systems, joint customers can now query across their AWS and Workday datasets in place, without moving or copying data, while retaining existing security controls in both environments.
From AWS, you can use Amazon SageMaker Unified Studio, Amazon EMR, AWS Glue, Amazon Redshift, and Amazon Athena to query Workday data through Workday Live Data Query or federate to Apache Iceberg tables in Workday Data Cloud through catalog federation. Configure a connection in SageMaker Unified Studio, AWS Glue, or AWS Lake Formation consoles and begin querying immediately. Access is governed by AWS and Workday permissions.
From Workday, you can register your AWS Glue Data Catalog Iceberg REST endpoint as an external catalog in Workday Analytics and query your AWS Iceberg tables directly. Common use cases include joining workforce data with business data for talent analytics, workforce planning, and machine learning.
This integration is available in all AWS commercial regions where AWS Glue is available. To learn more, see the AWS Glue User Guide, the Workday Data Cloud integration with AWS on Workday Data Cloud, and the AWS Big Data Blog post.
