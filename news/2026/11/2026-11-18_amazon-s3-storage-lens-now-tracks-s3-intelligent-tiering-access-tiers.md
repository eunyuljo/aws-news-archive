# Amazon S3 Storage Lens now tracks S3 Intelligent-Tiering access tiers

**날짜:** 2026년 11월 18일
**서비스:** S3
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-s3-storage-lens-s3-intelligent-tiering-access-tiers/

## 내용

Amazon S3 Storage Lens now provides storage metrics for each S3 Intelligent-Tiering access tier. You can see object counts and storage bytes in every tier across your buckets. This helps you track how your data moves between tiers, estimate storage costs, and measure your savings. 
S3 Storage Lens gives you visibility across your organization into storage usage and activity to help you optimize costs and performance. Access tier metrics appear in your S3 Storage Lens dashboards and metrics exports alongside your existing metrics. S3 Storage Lens also now publishes prefix metrics to AWS Billing and Cost Management, so you can allocate shared bucket costs to teams and applications with split cost allocation data for S3. 
To get started, enable access tier metrics in your S3 Storage Lens advanced tier configuration. Access tier metrics are available in all AWS Regions, except the AWS China Regions and the AWS GovCloud (US) Regions. To learn more, visit the S3 Storage Lens documentation. For pricing, visit the S3 pricing page.
