# AWS Transform extends application-centric migration across the lifecycle

**날짜:** 2026년 11월 20일
**서비스:** SystemsManager
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/aws-transform-application-centric-migration

## 내용

AWS Transform now puts applications at the center of every stage of the migration journey, so you can discover, plan, migrate, validate, and track the applications your business runs on rather than just the servers underneath them. Application-level grouping has been part of AWS rehost workflows for years, and AWS Transform now carries that same view through your entire migration. 
Enterprise migrations typically involve thousands of servers, but the questions that drive decisions are about applications. Using discovery data, AWS Transform identifies application boundaries and dependencies, then surfaces logical groupings of applications, each with its own total cost of ownership (TCO) and migration tracking. AWS Transform also adds built-in surveys, letting application owners validate ownership, system boundaries, and business criticality.&nbsp; 
A new migration dashboard keeps everyone aligned as the migration moves forward. It gives your team, partners, and leadership one current view of your applications, inventory, assessments, wave plans, and migration status. The dashboard pulls in data from every job in a workspace and updates as work progresses, so no one has to build or maintain separate status reports. You can customize the dashboard and ask questions about migration progress in chat.&nbsp; 
With a more connected workflow and improved visibility across the migration, AWS Transform lets you move to the cloud with more confidence.&nbsp;This capability is available in all AWS Regions where AWS Transform is offered. To learn more about migrating with AWS Transform, visit the product page.
