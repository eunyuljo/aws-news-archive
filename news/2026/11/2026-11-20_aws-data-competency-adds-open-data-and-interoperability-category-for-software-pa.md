# AWS Data Competency adds Open Data and Interoperability category for Software Partners

**날짜:** 2026년 11월 20일
**서비스:** General
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/data-competency-open-data-category/

## 내용

Today, AWS announces the Open Data and Interoperability category within the AWS Data Competency. The new category recognizes AWS Software Partners whose solutions keep customer data open and under customer control, letting multiple analytics engines and AI agents work on a single shared copy without moving or duplicating data.
AI agents need current, governed data they can reach. According to Gartner, Inc., most organizations are prioritizing AI-ready data investments, yet many Chief Data and Analytics Officers report their current data architecture needs modernization.
Partners in the Open Data and Interoperability category are validated for the following capabilities:
- Open formats: Data stored in Apache Iceberg, readable by any tool. - Interoperable storage: One copy of data on AWS. - Bidirectional catalogs: Metadata synced through the Iceberg REST Catalog. - Interchangeable engines: Customers pick the right engine for each job.
AWS Data Competency Partners also earn performance-based benefits including additional marketing and deal funding in 2027 and access to the AWS Data and AI Workshop.
Customers now have a trusted way to find Software Partners whose solutions are built from the ground up for openness and interoperability, and those Partners gain a clear way to stand out.
To learn more, read the APN Blog or visit the AWS Data Competency page.
