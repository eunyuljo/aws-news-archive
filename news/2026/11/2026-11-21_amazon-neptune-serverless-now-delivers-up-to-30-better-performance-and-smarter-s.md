# Amazon Neptune Serverless now delivers up to 30% better performance and smarter scaling

**날짜:** 2026년 11월 21일
**서비스:** Neptune
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/aws-neptune-serverless-r8g-generally-available

## 내용

Amazon Neptune Serverless now delivers up to 30% better performance at the same price per Neptune Capacity Unit, running on AWS Graviton4 processors. The new Graviton4-based platform also brings an improved scaling algorithm that adjusts Neptune Capacity Units (NCUs) more closely to your workload. This especially helps applications with many concurrent graph queries, such as real-time fraud detection, recommendation engines and generative AI applications that run graph lookups on every request. Neptune Serverless scales database capacity automatically as your application’s demand changes, so you can run graph applications with spiky or unpredictable traffic, such as fraud detection, recommendation engines, and generative AI applications, without provisioning for peak capacity. You pay only for the capacity you use. All newly created Neptune Serverless instances will be using AWS Graviton4 processors.  You can create new Neptune Serverless instances using AWS Management Console or the AWS CLI. You can upgrade existing clusters to the latest version in the next release. For more information on pricing and regional availability, refer to the Amazon Neptune pricing page and Neptune Serverless documentation.
