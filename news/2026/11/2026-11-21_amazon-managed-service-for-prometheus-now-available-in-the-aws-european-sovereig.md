# Amazon Managed Service for Prometheus now available in the AWS European Sovereign Cloud (Germany) region

**날짜:** 2026년 11월 21일
**서비스:** General
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/amp-aws-european-sovereign-cloud/

## 내용

Amazon Managed Service for Prometheus is now available in the AWS European Sovereign Cloud (Germany) region, along with Amazon Managed Service for Prometheus collector.&nbsp;Amazon Managed Service for Prometheus is a fully managed, Prometheus-compatible monitoring service, that&nbsp;helps you monitor and alert on operational metrics at scale. Customers in the AWS European Sovereign Cloud can now run Prometheus-compatible monitoring workloads in-region, which lowers latency for local workloads and keeps metric data within the region. 
Amazon Managed Service for Prometheus collector is a fully managed, agentless collector. It discovers and collects Prometheus metrics from your container workloads, so you do not need to run collection agents yourself. The collector sends metrics to an Amazon Managed Service for Prometheus workspace, where you query and analyze them. A workspace is a logical space for storing and querying Prometheus metrics.&nbsp; 
For the full list of regions where Amazon Managed Service for Prometheus is available, see the AWS Regional Services List. For pricing, see the Amazon Managed Service for Prometheus pricing page. To learn more, see the Amazon Managed Service for Prometheus user guide and the product page.
