# Announcing a new skill for AI agents in Amazon Textract Core

**날짜:** 2026년 11월 21일
**서비스:** Connect
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-textract-core-skill-ai-agents/

## 내용

Amazon Textract Core now lets AI agents extract text, tables, forms, and other data from documents through a skill, with no server to run or infrastructure to deploy. The skill guides an agent to the right Amazon Textract Core API for each document and includes a tested parser that converts the output into reading-order text and structured fields, such as answers to questions, receipt and invoice details, and identity document fields. Previously, teams that connected an agent to Amazon Textract had to build and maintain their own integration.
You ask in natural language, and the agent returns the answers you need. The skill processes multi-page PDFs and returns every page in reading order. It uses confidence scores to accept high-confidence results and flags the rest, so you can route them to your own review process. For example, you can ask an agent to turn a patient's intake form into structured data and flag unclear fields for staff review.
The skill is available at no additional charge, and standard Amazon Textract pricing applies. It is available in all commercial AWS Regions where Amazon Textract is available, including: US East (Ohio), US East (N. Virginia), US West (N. California), US West (Oregon), Asia Pacific (Mumbai), Asia Pacific (Seoul), Asia Pacific (Singapore), Asia Pacific (Sydney), Asia Pacific (Tokyo), Canada (Central), Europe (Frankfurt), Europe (Ireland), Europe (London), Europe (Paris), Europe (Spain), and Europe (Zurich). If you use the AWS MCP server with the aws-core plugin, your agent can load the skill automatically. The skill is also published in the AWS Agent Toolkit, so agents including Kiro, Claude Code, and Cursor can use it. To learn more, see the AWS Agent Toolkit on GitHub.
