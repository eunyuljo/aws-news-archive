# AWS Lambda adds support for Node.js 26

**날짜:** 2026년 11월 21일
**서비스:** Lambda
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/aws-lambda-nodejs-26/

## 내용

AWS Lambda now supports creating serverless applications using Node.js 26, for both Lambda Web Functions and Lambda Event Functions. Developers can use Node.js 26 as both a managed runtime and a base container image (Event Functions only). AWS will automatically apply updates to the managed runtime and base image as they become available.  Node.js 26 is the latest long-term support release of Node.js and is expected to be supported for security and bug fixes until April 2029. With this release, you can use the latest Node.js 26 features in Lambda, such as the Temporal API for easier date, time, and time zone handling, and enhancements to the Fetch API. You can use Node.js 26 with Powertools for AWS Lambda (TypeScript), a developer toolkit to implement serverless best practices and increase developer velocity. You can also use the full range of AWS deployment tools, including the Lambda console, AWS CLI, AWS Serverless Application Model (AWS SAM), AWS CDK, and AWS CloudFormation to deploy and manage serverless applications written in Node.js 26.  The Node.js 26 runtime is available in all Regions where Web Functions and Event Functions are available.  For more information about Node.js 26 in Lambda, refer to the Web Function and Event Function documentation. For more information about AWS Lambda, visit our product page.
