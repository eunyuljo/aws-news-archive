# AgentCore runtime instances are now available in six more AWS Regions

**날짜:** 2026년 11월 16일
**서비스:** EC2
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/agentcore-aws-regions/

## 내용

Amazon Bedrock AgentCore runtime instances are now available in six additional AWS Regions: US West (N. California), Canada (Central), Europe (London), Europe (Paris), Europe (Stockholm), and Asia Pacific (Seoul). Runtime instances run your agents on Amazon EC2 instances while AgentCore handles provisioning, patching, scaling, and lifecycle management. 
By expanding to these AWS Regions, more teams can use runtime instance capabilities such as GPU-accelerated, memory-optimized, or compute-optimized instance types, and long-running agent sessions of up to 14 days. You can run your agents closer to your users to reduce invocation latency, and keep agent instances, storage volumes, and session data in the Region that your data residency requirements call for. 
With this expansion, you can use runtime instances in the following AWS Regions: US East (N. Virginia), US East (Ohio), US West (N. California), US West (Oregon), Canada (Central), Europe (Frankfurt), Europe (Ireland), Europe (London), Europe (Paris), Europe (Stockholm), Asia Pacific (Mumbai), Asia Pacific (Seoul), Asia Pacific (Singapore), Asia Pacific (Sydney), and Asia Pacific (Tokyo). You are charged for managing the provisioned compute, in addition to your Amazon EC2 costs. 
To get started, see the following resources: 
 
 Supported AWS Regions in the Amazon Bedrock AgentCore Developer Guide 
 AgentCore pricing 
 Runtime instances and capacity providers in the Amazon Bedrock AgentCore Developer Guide
