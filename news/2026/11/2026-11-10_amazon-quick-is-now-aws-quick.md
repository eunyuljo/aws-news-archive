# Amazon Quick is now AWS Quick

**날짜:** 2026년 11월 10일
**서비스:** RDS
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-quick-aws-quick/

## 내용

Amazon Quick, the AI workspace built only for work, is now AWS Quick, a name that reflects the enterprise security and governance built into Quick from the start as an AWS service. The new name now appears across the Quick website, the web, desktop, and mobile apps, and AWS documentation. Existing customers don't need to take any action, and Quick works the same way it did before. 
Amazon Quick Sight, the business intelligence capability in Quick, is now AWS Quick Sight. Quick Sight customers&nbsp;can keep using their dashboards, datasets, and analyses just as they do today, with no changes to their data, settings, or pricing. 
With Quick, teams use AI agents to research, analyze, and act across the data and applications they already use, regardless of vendor. Quick understands your role, your team, and how your work connects, and anyone can build agents, apps, and automations in plain language that become shared assets for the whole team. Quick is HIPAA eligible and holds compliance certifications including FedRAMP, SOC 2, and ISO 27001. Your data stays in your environment and never trains&nbsp;someone else's models. 
AWS Quick is available in many AWS Regions. For more information, see the AWS Region table. 
To learn more, see AWS Quick.
