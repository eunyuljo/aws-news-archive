# Amazon Bedrock AgentCore Memory now supports short-term memory retention of up to 10 years

**날짜:** 2026년 11월 18일
**서비스:** Bedrock
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-bedrock-agentcore-memory-10-year-retention

## 내용

Amazon Bedrock AgentCore Memory now lets you keep short-term memory events for up to 10 years, up from one year. Developers can now use short-term memory as a long-lived record of agent conversations and interactions. This helps when that history needs to stay available for a long time, such as for compliance and audit, for users who come back after months away, or for agents that need to look back at past sessions. 
You set retention on the memory resource, and it's applied to each event when the event is created, so existing events keep their original retention. Standard short-term memory storage charges apply for as long as you keep the data. 
This feature is available in all AWS Regions where AgentCore Memory is available. To get started, see the AgentCore Memory documentation.&nbsp;&nbsp;&nbsp;&nbsp;
