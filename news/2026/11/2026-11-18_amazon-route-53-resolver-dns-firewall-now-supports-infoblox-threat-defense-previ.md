# Amazon Route 53 Resolver DNS Firewall now supports Infoblox Threat Defense (Preview)

**날짜:** 2026년 11월 18일
**서비스:** Route53
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/route53-dns-firewall-infoblox-preview/

## 내용

Amazon Web Services announces the preview of Infoblox Threat Defense on Amazon Route 53 Resolver DNS Firewall. Security administrators can now apply Infoblox threat intelligence directly in DNS Firewall rules to preemptively protect applications in their Amazon Virtual Private Clouds (VPCs) from cyber threats, by subscribing to the Infoblox product listing on AWS Marketplace from the Route 53 DNS Firewall console. 
With this launch, you can add Infoblox managed rules to your DNS Firewall rule groups to filter and block queries to malicious and high-risk domains at the DNS layer. Infoblox continuously updates its threat intelligence feeds to preemptively protect cloud workloads from phishing, malware, ransomware and other advanced attacks. You can apply these protections to DNS queries from your VPCs and to hybrid traffic forwarded through Route 53 Resolver endpoints, so security teams keep consistent DNS policies across AWS and on-premises environments and add a layer of protection on top of AWS managed domain lists. 
Infoblox Threat Defense on Route 53 DNS Firewall is available in preview in all AWS commercial Regions where Route 53 Resolver DNS Firewall is available. DNS Firewall Advanced customers can add Infoblox rules to existing rule groups at no additional DNS Firewall charge, and the Infoblox subscription in AWS Marketplace is free during preview. 
To get started, see the Route 53 DNS Firewall documentation. To view Route 53 pricing, visit the Route 53 pricing page. To learn more about the AWS Marketplace listing and pricing for Infoblox Threat Defense for Route 53 DNS Firewall, see here.
