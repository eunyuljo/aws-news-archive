# AWS Transform announces support for .NET 11 and expanded project types

**날짜:** 2026년 11월 21일
**서비스:** General
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/aws-transform-windows-dotnet-11/

## 내용

Today, AWS announced the general availability of .NET 11 support in AWS Transform for .NET. Support for VB.NET, desktop projects, and mobile projects, previously in preview, is also now generally available. You can modernize a broad range of Windows .NET workloads to the latest version of .NET and lower costs by running them on Linux. Modernized workloads gain the performance improvements, new C# language features, and improved diagnostics in .NET 11. 
AWS Transform modernizes both legacy .NET Framework applications (version 3.5 and later) and modern .NET applications (versions 5 through 10) to .NET 11. It transforms code written in C# and VB.NET. Supported project types include class libraries, console applications, ASP.NET web projects (MVC, Web API, and Web Forms), web services (ASMX and WCF), desktop applications (WinForms and WPF), mobile applications (Xamarin), unit test projects (MSTest, NUnit, and xUnit), and Windows services. You can run all transformed applications except desktop and mobile projects on Linux, which can reduce operating costs by up to 40%. 
This capability is available at no additional cost in all eight AWS Regions where AWS Transform is offered: US East (N. Virginia), Canada (Central), Asia Pacific (Mumbai), Asia Pacific (Seoul), Asia Pacific (Sydney), Asia Pacific (Tokyo), Europe (Frankfurt), and Europe (London). 
To learn more, see Modernizing .NET with AWS Transform in the AWS Transform User Guide.
