# AWS Elemental MediaConnect expands routing control and protocol support

**날짜:** 2026년 11월 18일
**서비스:** Connect
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/rtmp-support-aws-elemental-mediaconnect/

## 내용

With AWS Elemental MediaConnect, you now have more protocol support and routing control for your live video workflows.
First, MediaConnect now supports more protocols, including RTMP, RTMPS, and eRTMP, across both flows and router. RTMP is widely used by live streaming encoders and software such as OBS. With this support, you can now bring RTMP sources into MediaConnect and deliver to RTMP endpoints, such as social and live streaming platforms.
Second, the service adds three new routing capabilities:
- PID remapping on MediaConnect router reassigns transport stream PIDs inline, without transcoding.- Clean switch aligns input transitions on video boundaries for a more seamless switching experience.- SRT merge input mode bonds redundant SRT streams of the same content, reconstructing a clean feed when one path degrades to add resilience for lossy or long-haul contribution.
These capabilities are available in all AWS Regions where MediaConnect Router is available.
To learn more, see the AWS Elemental MediaConnect documentation.
