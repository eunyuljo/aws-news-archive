# Amazon Quick on desktop now uses your organization's existing Amazon Quick sign-in

**날짜:** 2026년 11월 02일
**서비스:** IAM
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-quick-desktop-organization-sign-in/

## 내용

For organizations that use Amazon Quick, the desktop application now signs users in with the same sign-in method the organization already uses for Quick on the web. Administrators no longer need to register an OIDC application in their identity provider or set up separate desktop sign-in before users can get started. If a user can sign in to Quick on the web, that user can sign in to the desktop application. 
To turn on desktop access, an administrator adds the desktop connector once in the Amazon Quick console. Users then enter their Quick account name, choose Sign In, and finish signing in through their browser. This works for accounts that use IAM Identity Center, IAM federation, or native Amazon Quick users. If your organization wants to manage desktop sign-in separately, you can still set up a dedicated identity provider configuration with providers such as Microsoft Entra ID, Google Workspace, Okta, or Ping Identity. 
Amazon Quick on desktop is available in AWS Regions that support the full Amazon Quick feature set. 
To get started, see Amazon Quick on desktop in the Amazon Quick User Guide.
