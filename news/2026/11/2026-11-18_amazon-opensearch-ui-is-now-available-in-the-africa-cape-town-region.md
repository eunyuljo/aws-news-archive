# Amazon OpenSearch UI is now available in the Africa (Cape Town) Region

**날짜:** 2026년 11월 18일
**서비스:** RDS
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/opensearch-ui-available-africa-cape-town-region

## 내용

Amazon OpenSearch UI has expanded to the AWS Africa (Cape Town) Region, bringing availability to 25 AWS Regions. OpenSearch UI provides a single endpoint to query, visualize, and analyze data across Amazon OpenSearch Service domains running OpenSearch version 1.3 or later and OpenSearch Serverless collections, including Classic and NextGen.  One OpenSearch UI application can connect to multiple domains and collections. Workspaces organize dashboards, saved queries, and other content, with purpose-built experiences for observability, security analytics, and search. The Discover interface supports multiple data sources and query languages, including Piped Processing Language (PPL) and SQL. It also includes a data selector, query autocomplete, and an updated design. OpenSearch UI runs separately from your domains and collections, giving you access to the latest UI capabilities without requiring cluster upgrades.  To get started, create an OpenSearch UI application using the Amazon OpenSearch Service console, AWS CLI, or AWS SDKs. OpenSearch UI is available at no additional charge. You pay only for the domains and collections it connects to. For the complete list of supported Regions, see OpenSearch UI endpoints and quotas. To learn more, see Using OpenSearch UI in Amazon OpenSearch Service&nbsp;in the Amazon OpenSearch Service Developer Guide.
