# Amazon Connect Health medical coding is now available in public preview

**날짜:** 2026년 11월 17일
**서비스:** Connect
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-connect-health-medical-coding/

## 내용

Today, AWS announces the public preview of medical coding in Amazon Connect Health, a HIPAA-eligible AI service that works alongside healthcare teams across patient engagement and point-of-care workflows. Medical coding uses existing clinical documentation to suggest ICD-10-CM and CPT codes, including E&amp;M levels and modifiers, for a provider or coder to review and approve before submission. You can integrate medical coding into your EHR or billing application through the Amazon Connect Health SDK, or use it with Amazon Connect Health ambient documentation. 
Each code links to the evidence that supports it and carries a confidence score, so reviewers can confirm a code before a claim goes out. In this public preview, you can choose to upload your organization's previously coded encounters, and the service builds a coding reference set specific to your organization. The corrections coders make feed that reference set and improve future coding suggestions.  Medical coding is available in public preview in the US East (N. Virginia) and US West (Oregon) AWS Regions.&nbsp;To learn more, see medical coding in the Amazon Connect Health user guide.&nbsp;
