# Amazon SageMaker adds new capabilities – improved blueprints and catalog experience, simplified data quality monitoring, and support for DuckDB 2.0 and DuckDB extensions

**날짜:** 2026년 11월 21일
**서비스:** S3
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-sagemaker-adds-new-capabilities/

## 내용

Improved blueprints: Amazon SageMaker Unified Studio now gives project teams more ownership of their data and resources, within governance policies that administrators set centrally. Additional releases include faster notebook queries through DuckDB 2.0 support and data quality monitoring at catalog scale.
Improved data quality monitoring: Teams can also profile entire catalogs and databases to keep data statistics current. Project members can get email notifications for all supported notification types, including data quality and data profiling runs.
Improved catalog experience: Administrators can now manage metadata forms, business glossaries, and custom asset types in one place, with a consistent experience across all domain types. They can also transfer asset ownership to the project that knows the data best. Members of that project can then curate those assets and approve or reject subscription requests themselves. With resource blueprints, administrators can allow projects to deploy approved resources, such as Amazon EMR Serverless applications. Teams can then provision what they need without waiting for an administrator.
Support for DuckDB 2.0 and extensions: SageMaker notebooks now support DuckDB 2.0 and DuckDB extensions. Data engineers, analysts, and data scientists get faster queries over Amazon S3 data, plus access to more file formats, data source connectors, and functions such as excel, geospatial and full-text search.
These capabilities are available in all AWS Regions where SageMaker Unified Studio is supported. To learn more, visit Manage the catalog, Working with data and catalog in IAM-based domains, Deploy on-demand blueprints, and Notebooks.
