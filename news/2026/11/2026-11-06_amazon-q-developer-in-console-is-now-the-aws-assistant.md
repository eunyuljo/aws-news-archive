# Amazon Q Developer in console is now the AWS assistant

**날짜:** 2026년 11월 06일
**서비스:** Personalize
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/q-developer-renamed-aws-assistant/

## 내용

Amazon Q Developer in the AWS Management Console and Console Mobile Apps is now called the AWS assistant. Previously, customers interacted with Amazon Q Developer across these surfaces. Now, the AWS assistant provides the same personalized, account-aware guidance and actions with a name that immediately communicates what the product does.
The AWS assistant simplifies how customers build, operate, and optimize on AWS. The AWS assistant is currently offered for free. Existing Amazon Q Developer Pro subscribers will automatically retain their Pro Tier capabilities under the AWS assistant.
The AWS assistant is available globally. To learn more, visit aws.amazon.com/products/assistant/.
