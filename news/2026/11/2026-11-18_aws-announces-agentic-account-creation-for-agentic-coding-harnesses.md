# AWS announces agentic account creation for agentic coding harnesses

**날짜:** 2026년 11월 18일
**서비스:** IAM
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/agentic-account-creation/

## 내용

AWS now enables agentic coding harnesses to open the new AWS sign-up experience for developers who don't have an AWS account yet. Previously, developers working in agentic coding environments like Claude Code, Codex, and Cursor had to manually navigate to aws.amazon.com, sign up for an AWS account and configure credentials before deploying workloads, interrupting the developer's experience. Now, developers can go from an idea to deploying a running application by the browser automatically opening, completing sign up and returning short-lived credentials to the harness. 
When developers sign up for AWS from their coding agent, they start with the new AWS experience. Their first project comes set up with a home Region, IAM role manager, and short-term credentials that refresh automatically, so the agent can start deploying right away. 
To try the new experience, configure the AWS Agent Toolkit in your agentic coding harness using the AWS MCP server setup guide or install the AWS Agent Toolkit plugin. On first authentication, you'll be prompted to open a browser directly to the AWS sign-up page. You can also initiate account creation via the AWS CLI by running aws signup (opens directly to sign-up) or aws login (opens the SignIn page with a Sign Up option). To learn more, see the AWS Agent Toolkit documentation or the AWS Account Documentation.
