# Amazon CloudFront now supports self-service increases in AWS Service Quotas

**날짜:** 2026년 11월 03일
**서비스:** CloudFront
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/cloudfront-self-service-quotas/

## 내용

Amazon CloudFront now supports AWS Service Quotas, so you can view, monitor, and request increases for 28 CloudFront quotas from the Service Quotas console or API. 
Until now, increasing a quota on resources such as distributions, cache policies, origins, or alternate domain names meant opening a support case and waiting for manual review. If you have AWS Business Support or higher, requests for limit increases within published thresholds are now approved automatically. For example, you can raise your distribution quota from 500 to 1,000, or the number of alternate domain names per distribution from 100 to 500, without opening a support case. Some quotas also publish usage metrics to Amazon CloudWatch every 5 minutes, so you can set alarms and request an increase before you reach a limit.. 
This feature is available in all AWS Regions where Amazon CloudFront is supported. 
To get started, visit the Service Quotas console to view and request increases for your CloudFront quotas. To learn more, see Amazon CloudFront quotas in the Amazon CloudFront Developer Guide.
