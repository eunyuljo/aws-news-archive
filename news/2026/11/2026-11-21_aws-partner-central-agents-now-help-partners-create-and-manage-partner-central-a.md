# AWS Partner Central Agents now help partners create and manage Partner Central and Marketplace support cases

**날짜:** 2026년 11월 21일
**서비스:** Translate
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/partner-central-agents-support/

## 내용

AWS Partner Central Agents now help AWS Partners create and manage AWS Partner Central and AWS Marketplace support cases in one place. The agents are available 24/7 and draw on Partner Central account details and authoritative, partner-specific knowledge from AWS to resolve most inquiries instantly. If a inquiry needs a support engineer, the agents will gather details and create a case. This reduces the time partners spend looking for help, and gives support teams the context they need to resolve cases faster. 
Partners can handle a case from start to finish in one chat, with the full record in AWS Support Center. To create a case, partners can start describing their issue to AWS Partner Central Agents or use the prompt "get support." The agents gather additional details necessary to resolve the case, set the category, and draft the description. Partners review and submit the case, and the agents route the case to the right support team. In the same chat, partners can view case communications, track progress, post replies, and add attachments. With this launch, Partner Central and AWS Marketplace cases also move to AWS Support Center. There, partners can view the full case history and translate support correspondence into Chinese, French, German, Japanese, Korean, Portuguese, and Spanish. 
The new support experience is available today to all AWS Partners and AWS Marketplace sellers in the AWS Partner Central console and through the AWS Partner Central Agents MCP server. With the MCP server, partners can bring the support experience into tools such as Kiro, AWS Quick, CRM systems, and other AI clients. To learn more, see Getting support in AWS Partner Central, Getting support for AWS Marketplace, and Getting started with the Partner Central Agents MCP server.
