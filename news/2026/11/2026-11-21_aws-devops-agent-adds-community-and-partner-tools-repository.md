# AWS DevOps Agent adds community and partner tools repository

**날짜:** 2026년 11월 21일
**서비스:** Config
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/devops-agent-tools-repository/

## 내용

AWS DevOps Agent now gives you ways to share and leverage skills, MCP servers, connectors, and custom agents that enhance the capabilities of your AWS DevOps Agent instances.
The AWS DevOps Agent Tools open source repository is a centralized, AWS-curated collection of tools that extend AWS DevOps Agent capabilities. Customers can import ready-to-use, quality-controlled tools directly into their DevOps Agent configurations to improve investigation quality and expand operational context. A growing community of AWS DevOps Agent users and partners, and AWS service and support teams, have contributed a growing collection of tools to the community, including several partner-managed connectors that simplify connecting AWS DevOps Agent to third party MCP servers. Partners providing connectors include: Bluebox, Bronto, Celonis, Clickhouse Observability, Coralogix, Cribl, Elastic, Halo, Honeycomb, LaunchDarkly, Neo4j, Sumo Logic, and Wiz.
To get started, browse the skills and connector catalogs from within your AWS DevOps Agent instance, or add and share your own tools by creating a PR within the AWS DevOps Agent Tools repository.
See all the latest AWS DevOps Agent features on the release history page. For the list of AWS Regions where AWS DevOps Agent is available, see the supported Regions table.
