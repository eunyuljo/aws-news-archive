# Amazon MWAA Serverless now supports custom and provider package operators

**날짜:** 2026년 11월 09일
**서비스:** S3
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/mwaa-serverless-custom-operators/

## 내용

Amazon MWAA Serverless now supports operators from Apache Airflow provider packages, such as HTTP, Snowflake, or dbt, and custom operators that you write. This gives data engineers the flexibility to integrate with more systems and build specialized workflow tasks without provisioning infrastructure.
To get started, add the provider package or your own operator to a code package, upload it to Amazon S3, and reference the operator in your workflow definition when you create or update a workflow.
This feature is available in all AWS Regions where Amazon MWAA Serverless is available. For a list of supported Regions, see Amazon MWAA Serverless Regions. To learn more, see Running custom code with Python, Bash, and custom operators in the Amazon MWAA Serverless User Guide.
