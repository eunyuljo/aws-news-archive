# AWS Quick enhances granular governance with the ability to restrict structured data sources

**날짜:** 2026년 11월 13일
**서비스:** Redshift
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/aws-quick-structured-data-source-restrictions/

## 내용

Today, AWS Quick is announcing the general availability of structured data connector restrictions through custom permissions. This capability gives administrators granular control over which types of data sources users can create, update, or share, helping organizations enforce data governance requirements while enabling self-service analytics.  With this feature, administrators can configure custom permissions profiles in Enterprise edition through the Quick UI, APIs, or AWS Command Line Interface. For example, an organization can allow users to create Amazon Redshift data sources while restricting the creation of file-upload data sources. Administrators can also prevent users from sharing data sources for a particular connector. Create, update, and share restrictions can be configured independently, providing more precise controls than restrictions that apply to all data source types.  This feature is now available in all supported AWS Quick Regions listed here. To learn more, check our documentation here.
