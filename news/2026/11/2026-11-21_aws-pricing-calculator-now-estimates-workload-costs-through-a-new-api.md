# AWS Pricing Calculator now estimates workload costs through a new API

**날짜:** 2026년 11월 21일
**서비스:** General
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/aws-pricing-calculator-api/

## 내용

AWS Pricing Calculator now offers GetUsageLinesEstimatedCost, a new API that returns the estimated cost of a planned workload in a single API call. You send up to 500 usage lines in one request and get the cost back right away, without saving an estimate to your account. While workload estimates let you create and save an estimate in Pricing Calculator, GetUsageLinesEstimatedCost returns a cost on demand, directly in your own tools and workflows. 
You can choose from three rate types: public On-Demand rates, your rates after discounts, or your rates after discounts plus Savings Plans and Reserved Instances. The API returns the cost of each line and the total. For example, you can check what a design will cost before you deploy it, or let an AI coding agent call the API to price a workload while it helps you design it. 
GetUsageLinesEstimatedCost is generally available at no additional charge in all AWS Regions, except the AWS GovCloud (US) Regions and the China Regions. 
To learn more, see&nbsp;GetUsageLinesEstimatedCost in the AWS Billing and Cost Management API Reference, or&nbsp;visit the AWS Pricing Calculator product page.
