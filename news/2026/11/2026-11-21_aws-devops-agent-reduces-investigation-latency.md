# AWS DevOps Agent reduces investigation latency

**날짜:** 2026년 11월 21일
**서비스:** General
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/devops-agent-reduces-latency/

## 내용

When an incident is occurring, mean time to recover needs to be as fast as possible.
With this launch, incident investigations performed by AWS DevOps Agent complete faster. Investigations now also include a real-time summary that is updated with the current state of an investigation, so initial findings and observations surface quickly, before a final root cause and mitigation plan are created. For customers using AWS DevOps Agent's built in Slack integration, these summaries are also automatically pushed to the relevant Slack channel.
See all the latest AWS DevOps Agent features on the release history page. For the list of AWS Regions where AWS DevOps Agent is available, see the supported Regions table.
