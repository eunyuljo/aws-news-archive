# Amazon Connect Customer now supports batch actions on up to 100 cases at once

**날짜:** 2026년 11월 13일
**서비스:** Connect
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/connect-batch-actions-100-cases/

## 내용

Cases in Amazon Connect Customer now lets agents and supervisors assign, comment on, and update the status of up to 100 cases at once, so teams spend less time on repetitive case updates. When one issue affects many customers, such as a shipping delay or a service outage, teams no longer need to update each case one at a time. Agents and supervisors with the appropriate permissions can select the related cases and change the assignee, add a comment, or close them in a single action. Developers can also use batch APIs to make the same updates programmatically.
Cases is available in the following AWS Regions: US East (N. Virginia), US West (Oregon), Canada (Central), Europe (Frankfurt), Europe (London), Asia Pacific (Seoul), Asia Pacific (Singapore), Asia Pacific (Sydney), Asia Pacific (Tokyo), and Africa (Cape Town). To learn more and get started, visit the Cases webpage and documentation.
