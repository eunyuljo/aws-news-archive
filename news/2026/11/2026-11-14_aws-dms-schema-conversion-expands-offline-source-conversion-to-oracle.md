# AWS DMS Schema Conversion expands offline source conversion to Oracle

**날짜:** 2026년 11월 14일
**서비스:** EKS
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/aws-dms-schema-conversion-expands-offline-source-conversion-to-oracle/

## 내용

AWS Database Migration Service (DMS) Schema Conversion now supports offline source conversion for Oracle Database. You can convert Oracle schemas and code without direct connectivity to your source databases. You can extract metadata using standard database commands in your own environment, then upload it to DMS Schema Conversion for processing. This removes the need for security reviews, firewall changes, and VPN setup that delay migration projects, and delivers the same conversion results as the connected approach. 
Offline Source suits organizations whose security policies restrict external tool access to production Oracle databases. Database administrators can generate human-readable metadata files within their existing environment. Security teams can review the commands and output before upload, simplifying approval. By removing the connectivity requirement, Offline Source turns weeks of security reviews into a simple command-and-upload workflow. 
Offline Source supports all DMS Schema Conversion targets at no additional conversion charge. For regional availability, see the Supported AWS Regions page. To get started, see Using Offline Source in the DMS Schema Conversion documentation.&nbsp;To learn how to run offline assessment and conversion with AI agents, read the launch blog post.&nbsp;
