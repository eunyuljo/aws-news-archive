# Amazon Connect Customer agent assist now supports interactive responses

**날짜:** 2026년 11월 17일
**서비스:** RDS
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/Connect-Custom-agent-interactive-responses

## 내용

Amazon Connect Customer agent assist now supports interactive components, including cards, carousels, buttons, and input fields. The AI agent analyzes conversation context in real time, recommends actions, retrieves information, and executes tasks on behalf of contact center agents using MCP tools in Connect Customer or third-party services. Interactive responses let agents review information, provide details, select options, and confirm actions without manually typing a separate request for each action. The AI agent can also recommend step-by-step guides, cases, customer profiles, and third-party applications that agents can open with one click. 
For example, when a customer calls to dispute a charge, the AI agent can dynamically generate an interactive list of the customer’s recent transactions. The agent can select the disputed transaction, provide or confirm the required details, and approve the action. The AI agent can then use a connected tool to create the dispute request and display confirmation in the agent workspace. 
This feature is available in all AWS Regions where Amazon Connect Customer agent assist is available. To learn more and get started, see Agent Assist in the Amazon Connect Administrator Guide.&nbsp;
