# Announcing the general availability of a new AWS Local Zone in Bogotá, Colombia

**날짜:** 2026년 11월 20일
**서비스:** S3
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/aws-local-zone-bogota-colombia/

## 내용

Today, AWS announces the general availability of a new Local Zone in Bogotá, Colombia, bringing AWS infrastructure closer to end users for applications that require single-digit millisecond latency. You can use the Bogotá Local Zone for workloads such as real-time gaming, live video streaming, medical imaging, and financial transaction processing. 
AWS Local Zones are infrastructure deployments that place compute, storage, networking, and other select AWS services closer to metropolitan areas, with the same APIs and tools as AWS Regions. You pay only for what you use, with no minimum commitment. Pricing options include On-Demand, Savings Plans, and Spot Instances. AWS Local Zones are available in more than 30 locations worldwide. 
The AWS Local Zone in Bogotá supports&nbsp;Amazon Elastic Compute Cloud (Amazon EC2) with C7i, M7i, and R7i instances, Amazon S3 with the One Zone-Infrequent Access storage class, Amazon EBS with local snapshots and volume types gp3, gp2, and io1, Amazon Elastic Container Service (Amazon ECS), Amazon Elastic Kubernetes Service (Amazon EKS), Amazon Virtual Private Cloud (Amazon VPC), AWS Direct Connect, and Application Load Balancer. &nbsp; 
To get started, enable the AWS Local Zone in Bogotá (us-east-1-bog-1a) from the Regions and Zones tab in the AWS Global View or by using the ModifyAvailabilityZoneGroup API. For pricing information, visit the AWS Local Zones pricing page.&nbsp;To learn more, visit the AWS Local Zones overview page.
