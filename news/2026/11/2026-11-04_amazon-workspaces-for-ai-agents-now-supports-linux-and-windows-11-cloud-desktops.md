# Amazon WorkSpaces for AI agents now supports Linux and Windows 11 cloud desktops

**날짜:** 2026년 11월 04일
**서비스:** IAM
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/workspaces-ai-agents-linux-windows-11

## 내용

WorkSpaces for AI agents now supports Linux and Windows 11 cloud desktops, in addition to Windows Server. You can run each AI agent on the operating system that its workflows and applications require. Your agents can then work in the same environments that your workforce already uses, without re-platforming.&nbsp; 
Linux desktops give agents full root access to the operating system where many developers already build, test, and automate agentic workflows. Agents can take on developer tasks, such as running builds, tests, and scripts, within the enterprise-grade security and governance controls you already rely on. Windows 11 desktops let agents work in the enterprise applications your teams depend on every day. 
Linux and Windows 11 desktops have the same security and governance controls as Windows Server desktops. These include network isolation, IAM-based access, and the compliance boundaries your organization already has in place. 
To get started operating AI agents on WorkSpaces, visit: https://docs.aws.amazon.com/appstream2/latest/developerguide/agent-access.html.
