# Second-generation AWS Outposts racks now supported in the AWS European Sovereign Cloud (Germany) Region

**날짜:** 2026년 11월 20일
**서비스:** Connect
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/aws-outposts-thf-european-sovereign/

## 내용

Second-generation AWS Outposts racks are now supported in the AWS European Sovereign Cloud (Germany) Region. Outposts racks extend AWS infrastructure, AWS services, APIs, and tools to virtually any on-premises data center or colocation space for a truly consistent hybrid experience. 
Organizations of every size, from startups to enterprises to public sector agencies, can now order Outposts racks connected to this newly supported Region to optimize for latency and data residency needs. This regional expansion provides additional flexibility in the number of AWS Regions that customers' Outposts can connect to. 
To learn more about second-generation Outposts racks, read the AWS Outposts blog post&nbsp;and user guide.&nbsp;For the latest list of countries and territories and the AWS Regions where second-generation Outposts racks are supported, see the&nbsp;AWS Outposts FAQs page. For pricing information in the AWS European Sovereign Cloud (Germany) Region, please refer to this page.
