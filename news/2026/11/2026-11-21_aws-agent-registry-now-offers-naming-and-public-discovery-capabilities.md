# AWS Agent Registry now offers naming and public discovery capabilities

**날짜:** 2026년 11월 21일
**서비스:** RDS
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/agent-registry-naming-public-discovery/

## 내용

AWS Agent Registry now offers public naming capabilities, making it easy to attach verified domain names to your agents and AI tools. Developers and network admins can perform domain verification checks to prove domain ownership, then associate the verified domain names with their agents to promote them for public visibility beyond their registry and AWS account.
Previously, developers had to manually configure how agents discover and connect to one another, which added complexity to building multi-agent systems. With this launch, since the public agent records are anchored to a verified domain identity, you can confirm the source of an agent before connecting to it. Once published, agent records are searchable by any AWS-authenticated user using both semantic and lexical search.
This capability is available at no additional charge at this time in all AWS Regions where AWS Agent Registry is available. To learn more about naming and public discovery, visit the AWS Agent Registry documentation.
