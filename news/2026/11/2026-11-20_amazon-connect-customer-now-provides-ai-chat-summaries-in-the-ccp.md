# Amazon Connect Customer now provides AI chat summaries in the CCP

**날짜:** 2026년 11월 20일
**서비스:** Connect
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/connect-ai-chat-summaries-ccp/

## 내용

Amazon Connect Customer now provides agents with a generative AI-powered post-contact summary of each chat conversation inside the Contact Control Panel (CCP) within seconds after the chat ends, so agents can complete after contact work from the summary instead of rereading the transcript. The summary covers what the customer needed, the actions the agent took, and any open items, and it appears at the end of the chat transcript. Conversational analytics already generates these summaries for voice and email contacts in the CCP, and this launch adds chat.  An airline agent who finishes a flight rebooking chat sees the new travel date, the fare difference charged, and the confirmation sent, then writes the wrap-up note from those three facts. Summaries follow your flow's redaction settings and use the same security profile permissions as voice summaries, so administrators who already enabled voice summaries can turn on chat analytics with post-contact summary in the Set recording and analytics behavior block.  To learn more, see View generative AI-powered post-contact summaries in Connect Customer.
