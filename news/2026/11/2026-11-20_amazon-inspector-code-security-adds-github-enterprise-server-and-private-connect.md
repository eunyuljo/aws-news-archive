# Amazon Inspector Code Security adds GitHub Enterprise Server and private connectivity

**날짜:** 2026년 11월 20일
**서비스:** VPC
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/inspector-code-ghes-private-network/

## 내용

Amazon Inspector Code Security now supports GitHub Enterprise Server (GHES) integration and private network connectivity for GHES and GitLab Self-Managed. Code Security is also launching automatic fix pull requests in public preview. Organizations that host GHES or GitLab Self-Managed in private networks can now connect through Amazon Virtual Private Cloud (Amazon VPC) configurations or AWS CodeConnections, so they can scan repositories without opening their firewalls to the entire AWS IP address range. 
Amazon Inspector Code Security scans first-party application source code, third-party dependencies, and Infrastructure as Code for vulnerabilities in repositories on GitHub, GHES, and GitLab Self-Managed. With automatic fix pull requests, Amazon Inspector turns its suggested fix into a pull request that developers review and choose whether to merge, instead of applying the fix by hand. It opens pull requests only for high-confidence fixes to static application security testing (SAST) findings at or above a severity you set. 
These features are available in all 10 AWS Regions where Amazon Inspector Code Security is available: US East (N. Virginia), US East (Ohio), US West (Oregon), Europe (Frankfurt), Europe (Ireland), Europe (London), Europe (Stockholm), Asia Pacific (Tokyo), Asia Pacific (Sydney), and Asia Pacific (Singapore). To learn more, see the Amazon Inspector User Guide and the Amazon Inspector product page.
