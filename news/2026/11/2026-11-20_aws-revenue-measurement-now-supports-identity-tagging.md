# AWS Revenue Measurement now supports Identity Tagging

**날짜:** 2026년 11월 20일
**서비스:** IAM
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/revenue-measurement-identity-tagging/

## 내용

AWS Revenue Measurement (previously Partner Revenue Measurement) provides measurement of AWS consumption driven by Partner solutions. Today, AWS announces Identity Tagging in AWS Revenue Measurement, a new way for Partners to get attributed revenue visibility for the AWS usage their solutions drive. Partners can now tag the IAM user or role their solution uses instead of tagging individual resources or decorating individual SDK/API calls. This makes attribution simpler and needs no code changes. 
Until now, Partners using Resource Tagging had to apply tags to each resource their solution created or managed. That could be hard to keep consistent across customer environments. With Identity Tagging, Partners apply a tag to the IAM role or user their solution uses in the AWS account. AWS Revenue Measurement then attributes usage from resources created by that identity to the Partner's product. Identity Tagging works alongside existing methods such as Resource Tagging, User Agent string, and SaaS Account Tagging, so Partners can pick the method that best fits their architecture. 
AWS Revenue Measurement is generally available in all commercial regions. To learn more, review the AWS Revenue Measurement onboarding guide.
