# AWS Security Hub now detects when vulnerable software is running on Amazon EC2 instances

**날짜:** 2026년 11월 18일
**서비스:** EC2
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/security-hub-detects-vulnerable-software/

## 내용

AWS Security Hub now detects when software with a known vulnerability is actively running on your Amazon EC2 instances. Exposure findings now include a new trait, *The EC2 instance is running software with a known vulnerability*. These findings get a higher severity rating than findings for the same vulnerability where the software isn't running. This helps your security team focus on the vulnerabilities that pose the greatest risk,&nbsp;without investing time and resources to investigate if the software is actually in use. 
Security teams managing thousands of instances can now prioritize patching based on actual runtime risk.&nbsp; Security Hub correlates data from Amazon GuardDuty Runtime Monitoring and Amazon Inspector VM Scanner to detect running vulnerable software. It then combines this with other signals to generate exposure findings for EC2 resources that may be at risk, so you can prioritize response and remediation. 
This capability is available at no additional cost with the AWS Security Hub Essentials plan in all AWS Regions where Security Hub is available . To learn more, see the AWS Security Hub User Guide, the exposure definition in Remediating exposures for EC2, the AWS Security Hub product page, the GuardDuty Runtime Monitoring User Guide, and the Amazon Inspector VM Scanner User Guide. For the full list of Regions, see the AWS Regional Services List.
