# AWS Lambda adds support for Python 3.15

**날짜:** 2026년 11월 21일
**서비스:** Lambda
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/aws-lambda-python-315/

## 내용

AWS Lambda now supports creating serverless applications using Python 3.15. Python 3.15 is generally available for Lambda Event Functions and is available in public preview for Lambda Web Functions. This is the first Python runtime for Web Functions, which until now only supported Node.js. With this launch, developers can also build web applications and APIs on Web Functions in Python. Developers can use Python 3.15 as both a managed runtime and a base container image (Event Functions only), and AWS will automatically apply updates to the managed runtime and base image as they become available.  Python 3.15 is the latest release of Python. With this release, you can use the latest Python 3.15 features in Lambda, such as explicit lazy imports that can reduce function startup time, the new frozendict and sentinel built-in types, and an improved JIT compiler. You can use Python 3.15 with Powertools for AWS Lambda (Python), a developer toolkit to implement serverless best practices and increase developer velocity. You can also use the full range of AWS deployment tools, including the Lambda console, AWS CLI, AWS Serverless Application Model (AWS SAM), AWS CDK, and AWS CloudFormation to deploy and manage serverless applications written in Python 3.15.  The Python 3.15 runtime is available in all Regions where Event Functions and Web Functions are available.  For more information about Python 3.15 in Lambda, refer to the Event Function and Web Function documentation. For more information about AWS Lambda, visit our product page.
