# Amazon Cognito announces 99.99% Service Level Agreement for the Plus feature plan

**날짜:** 2026년 11월 06일
**서비스:** Cognito
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-cognito-sla-update/

## 내용

Starting November 1, 2026, the Amazon Cognito Service Level Agreement (SLA) commits to a Monthly Uptime Percentage of 99.99% for user pools on the Plus feature plan, up from 99.9%. User pools already on Plus are automatically covered by the new Service Commitment. User pools on Essentials and Lite stay at the 99.9% Service Commitment with no change to their terms. 
To qualify for the 99.99% Service Commitment, you can switch a user pool to the Plus feature plan using the AWS Management Console, AWS Command Line Interface (CLI), or AWS Software Development Kits (SDKs). The Plus feature plan also includes threat protection features such as adaptive authentication, compromised credentials detection, and threat and user activity logging and export. 
For full terms and exclusions, see the Amazon Cognito SLA.&nbsp;To learn more about feature plans, see user pool feature plans.&nbsp;&nbsp;&nbsp;&nbsp;
