# Amazon WorkSpaces now lets developers enable Nested Virtualization

**날짜:** 2026년 11월 20일
**서비스:** General
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/workspaces-nested-virtualization/

## 내용

Developers on Amazon WorkSpaces Personal can now turn on Nested Virtualization for their own WorkSpaces from the Windows WorkSpaces client, without asking an administrator to make each change. Once an administrator grants self-service permission for the directory, developers can run Docker Desktop, Windows Subsystem for Linux (WSL2), and Android emulators directly on their WorkSpaces. 
Administrators can now grant a directory-level self-service permission for Nested Virtualization. Once granted, end users can turn the setting on or off for their own Windows WorkSpace from the WorkSpaces client. Administrators keep control because the permission is set per directory. 
Self-service is supported on WorkSpaces Personal, using the Desktop Cloud Visualization (DCV) protocol, on Standard bundles and higher. Power (4 vCPU) or higher is recommended. Value and Graphics bundles are not supported. Nested virtualization is available in all AWS Regions where Amazon WorkSpaces is available, excluding the China (Ningxia) Region. There is no additional charge for supported bundles. For more information, visit the Amazon WorkSpaces documentation on Nested Virtualization. For pricing, visit the Amazon WorkSpaces pricing page.
