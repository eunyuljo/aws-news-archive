# Amazon EC2 launches performance status checks and new utilization metrics for EC2 Detailed Monitoring

**날짜:** 2026년 11월 20일
**서비스:** EC2
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/ec2-performance-status-checks/

## 내용

Customers can now use Amazon EC2 performance status checks and new utilization metrics for EC2 Detailed Monitoring to observe and act on the performance of their EC2 workloads without setup within the instance, complementing their in-guest tooling. Customers running performance-sensitive EC2 workloads can use these signals to monitor their CPU and GPU resources, tune capacity needs, and troubleshoot application issues. 
EC2 performance status checks identify nonterminal hardware conditions that impact performance on accelerated computing instances. These checks also recommend an action, such as rebooting to complete GPU memory row remapping without replacing the instance. The additions to Detailed Monitoring include support for OpenTelemetry metrics, one-minute GPU metrics that help teams tune accelerated workloads, and a new, higher resolution 10-second CPU utilization metric that helps customers size and scale compute capacity using EC2 Auto Scaling. Customers can selectively opt into these new metrics using categories that they can easily apply to their instances across their fleet. Together, these new capabilities make it easier for customers to manage their compute resources. 
EC2 performance status checks are available at no additional charge. EC2 Detailed Monitoring metrics are opt-in and incur standard CloudWatch charges for EC2 Detailed Monitoring. These capabilities are available in all commercial AWS Regions and the AWS GovCloud (US) Regions. 
To learn more, see EC2 Detailed Monitoring documentation and EC2 performance status checks documentation.
