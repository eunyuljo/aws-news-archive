# AWS HealthOmics now supports Nextflow version 26.10

**날짜:** 2026년 11월 19일
**서비스:** Config
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/aws-healthomics-nextflow-version-26-10/

## 내용

AWS HealthOmics now supports Nextflow version 26.10, which adds enhancements such as static typing, pipeline composition, and configurable report directories. AWS HealthOmics is a HIPAA-eligible service that helps healthcare and life sciences customers accelerate scientific breakthroughs at scale with fully managed bioinformatics workflows. 
In Nextflow 26.10, static typing lets workflow developers declare types for parameters, inputs, and outputs, and the nextflow lint command reports type errors before any task is submitted.&nbsp;Pipeline composition lets developers include a statically typed pipeline from their workflow package and call it like a sub-workflow, so validated pipelines can be reused as building blocks. For example, you can include an alignment pipeline and a variant-calling pipeline in one workflow, and each sample moves to variant calling as soon as alignment finishes. Collection parameters can now be loaded directly from CSV, JSON, or YAML sample sheets into record types. Execution reports, timelines, and traces can be written to a directory inside the workflow output, and HealthOmics exports them with the run outputs. 
You can use Nextflow 26.10 in the following AWS Regions: US East (N. Virginia, Ohio), US West (Oregon), Europe (Frankfurt, Ireland, London), Israel (Tel Aviv), and Asia Pacific (Singapore, Seoul, Tokyo). To learn more, visit the Nextflow version release notes documentation.
