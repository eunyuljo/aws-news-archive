# Amazon MWAA now supports cost allocation tags

**날짜:** 2026년 11월 06일
**서비스:** General
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-mwaa-cost-allocation-tags/

## 내용

Amazon Managed Workflows for Apache Airflow (Amazon MWAA) now supports cost allocation tags. Tags you apply to an Amazon MWAA environment now propagate to the compute that runs it, including workers, schedulers, and web servers. You can then track Amazon MWAA spend by tag in AWS Cost Explorer and AWS Cost and Usage Reports.
With this launch, platform teams can show back or charge back Airflow costs to the team, project, or cost center that owns each environment. You can use cost allocation tags when you create a new environment or update an existing one. To get started, tag your environment using the Amazon MWAA console, AWS CLI, or Amazon MWAA API, then activate the tag key as a cost allocation tag in the AWS Billing and Cost Management console.
This feature is available in all AWS Regions where Amazon MWAA is available. For more information, see the AWS Region table. To learn more, visit Cost allocation tags in Amazon MWAA in the Amazon MWAA User Guide.
