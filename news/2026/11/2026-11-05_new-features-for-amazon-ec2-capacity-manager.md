# New features for Amazon EC2 Capacity Manager

**날짜:** 2026년 11월 05일
**서비스:** EC2
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/ec2-capacity-manager-supportability-and-fulfillment/

## 내용

Amazon EC2 Capacity Manager now offers real-time supportability checks and capacity fulfillment metrics. Real-time supportability checks help customers find capacity by scoring how well each instance type and Availability Zone can support a request, without launching or reserving instances. Capacity fulfillment metrics show how much capacity was delivered against the amount requested. 
Global enterprises that run thousands of workloads across hundreds of accounts often spread each one across multiple instance types and Availability Zones, giving Amazon EC2 more options to fulfill each request. Starting today, customers can use the supportability checks in Capacity Manager to understand which Availability Zones and instance types give them the best chance of getting the capacity they need. The check returns a High, Medium, or Low score for each option, plus an overall score. Additionally, with fulfillment metrics, customers can measure fulfillment rates across their AWS organization, accounts, Regions, and tagged workloads, with a breakdown by instance type and Availability Zone, to show how well those choices are working. 
Both capabilities are included with AWS Unified Operations, the AWS Support plan for global enterprises running mission-critical workloads, and are available in all commercial AWS Regions. 
To learn more, read Plan and measure EC2 flexibility with Amazon EC2 Capacity Manager&nbsp;on the AWS Compute Blog and see the Amazon EC2 Capacity Manager user guide. To get started, visit the Capacity Manager console.
