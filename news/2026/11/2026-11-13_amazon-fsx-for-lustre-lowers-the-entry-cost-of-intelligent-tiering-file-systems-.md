# Amazon FSx for Lustre lowers the entry cost of Intelligent-Tiering file systems by 75%

**날짜:** 2026년 11월 13일
**서비스:** FSx
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/fsx-lustre-intelligent-tiering-lower-throughput/

## 내용

Amazon FSx for Lustre is reducing the minimum provisioned throughput capacity and metadata IOPS on Intelligent-Tiering file systems by 75%, allowing you to use Intelligent-Tiering even more cost-effectively for high-performance computing (HPC) and machine learning workloads that start with small datasets and grow over time. 
The FSx for Lustre Intelligent-Tiering storage class delivers the lowest-cost and only fully elastic Lustre file storage in the cloud. It is optimized for workloads that mix hot and cold data and do not require consistent SSD-level performance. A file system's throughput capacity determines the read and write speeds supported by its underlying file servers, and its level of metadata IOPS determines how many files and directories you can create, read, and delete per second. Today’s launch reduces the minimum throughput capacity on an Intelligent-Tiering file system from 4,000 to 1,000 MBps and the minimum metadata performance from 6,000 to 1,500 IOPS.&nbsp; 
The lower throughput capacity and metadata IOPS levels are available on new FSx for Lustre Intelligent-Tiering file systems in all AWS Regions where the Intelligent-Tiering storage class is available. To learn more, see Performance characteristics of Intelligent-Tiering storage class in the Amazon FSx for Lustre User Guide.
