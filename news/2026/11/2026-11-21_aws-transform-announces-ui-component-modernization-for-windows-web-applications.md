# AWS Transform announces UI component modernization for Windows web applications

**날짜:** 2026년 11월 21일
**서비스:** General
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/aws-transform-ui-windows/

## 내용

Today, AWS announced the general availability of third-party UI component porting for ASP.NET web site modernization in AWS Transform. When AWS Transform modernizes a legacy ASP.NET web site, it now detects dependencies on popular third-party UI component libraries. You can replace them with license-free Microsoft-native and open-source components, or you can keep using vendor UI libraries. 
AWS Transform rewrites legacy ASP.NET web sites for ASP.NET Core UI frameworks. When the AWS Transform for .NET modernization agent finds a dependency on a popular third-party UI library, it offers two options. The first option is for customers who require open-source software only. The agent replaces each proprietary control with a Microsoft-native or open-source control on the target UI framework and removes the original dependency. The second option is for customers who want to keep using vendor libraries. The agent adds code comments and next-step instructions for moving to an equivalent vendor library on the target UI framework. You then arrange licensing with the vendor and finish the port using an AI coding companion. 
This capability is available at no additional cost in all eight AWS Regions where AWS Transform is offered: US East (N. Virginia), Canada (Central), Asia Pacific (Mumbai), Asia Pacific (Seoul), Asia Pacific (Sydney), Asia Pacific (Tokyo), Europe (Frankfurt), and Europe (London). 
To learn more, see Porting UI layer code in the AWS Transform User Guide.
