# AWS Health now supports resource and account tags

**날짜:** 2026년 11월 20일
**서비스:** EventBridge
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/aws-health-supports-tags/

## 내용

AWS Health now supports resource and account tags in Health events. This new capability enables you to enrich Health events with resource tags and account tags, providing additional context to help you manage and respond to events more effectively. 
With this feature, you can now view resource tags directly within Health events for supported AWS services. This allows you to quickly identify which resources are affected and understand their business context without needing to navigate to individual service consoles. Additionally, account-level tags help you categorize and filter events across your organization, making it easier to route notifications and automate responses based on your organizational structure. 
This enhancement is particularly valuable for organizations managing large-scale AWS deployments. By leveraging tags in Health events, you can streamline incident response workflows, improve cost allocation tracking for health-related events, and enable more granular event filtering in AWS Health Dashboard and AWS Health API responses. 
The feature integrates seamlessly with Amazon EventBridge, allowing you to create event-driven automation that responds to tagged resources and accounts. This enables sophisticated routing and handling of Health events based on tag values, supporting use cases such as automatically creating tickets in your IT service management system or sending targeted notifications to specific teams. 
To enable tag enrichment, visit the AWS Health Dashboard or view the AWS Health User Guide for more information.
