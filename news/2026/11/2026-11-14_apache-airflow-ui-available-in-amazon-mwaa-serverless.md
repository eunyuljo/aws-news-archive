# Apache Airflow UI available in Amazon MWAA Serverless

**날짜:** 2026년 11월 14일
**서비스:** RDS
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/airflow-ui-for-mwaa-serverless/

## 내용

Amazon MWAA Serverless provides the native Apache Airflow UI for your workflows. You can browse workflows, inspect workflow runs and task instances, read task logs, view a workflow's source and versions, and start a workflow run. The UI uses the permissions of the IAM identity that opens it and shows only what that identity can read, so read-only access is possible. AWS CloudTrail records the calls the UI makes under your identity.
You can open the Airflow UI from the Amazon MWAA console, the AWS CLI, or the API. Teams already familiar with Airflow can use the interface they know to work with their workflows.
This feature is available in all AWS Regions where Amazon MWAA Serverless is available. For more information, see the AWS Region table.
To get started, see Access the Airflow UI. Apache Airflow is a trademark of the Apache Software Foundation.
