# AWS Compute Optimizer now supports additional Amazon EC2 instance types in the AWS GovCloud (US) Regions

**날짜:** 2026년 11월 11일
**서비스:** EC2
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/10/aws-compute-optimizer-amazon-ec2/

## 내용

AWS Compute Optimizer now provides rightsizing recommendations for 389 additional Amazon Elastic Compute Cloud (Amazon EC2) instance types in AWS GovCloud (US-West) and 276 in AWS GovCloud (US-East) Regions. Customers running regulated and government workloads can find the same cost and performance opportunities on current-generation instance types without manual analysis. 
Compute Optimizer has expanded support to include the latest generation families in every workload category. The additions include Compute Optimized (C7i, C7i-flex, C8g, C8gn), General Purpose (M7i, M7i-flex, M8g, M8gd, M8i, M8i-flex), Memory Optimized (R7i, R8g, R8gd, R8i, R8i-flex), Memory Intensive (X2iedn, X8i), and Storage Optimized (I7i, I7ie, I8g, I8ge) instance types. With this expansion, Compute Optimizer supports 724 instance types across 102 families in AWS GovCloud (US-West) and 542 instance types across 69 families in AWS GovCloud (US-East), in both EC2 instance and EC2 Auto Scaling group recommendations. 
This expanded coverage is available today at no additional cost in the AWS GovCloud (US-West) and AWS GovCloud (US-East) Regions. You can start using Compute Optimizer through the AWS Management Console, AWS CLI, or AWS SDK. To learn more, see the AWS Compute Optimizer product page and AWS Compute Optimizer in the AWS GovCloud (US) User Guide.
