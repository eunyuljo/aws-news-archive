# AWS Transform supports optimized storage for server migration

**날짜:** 2026년 11월 19일
**서비스:** Config
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/aws-transform-optimized-storage/

## 내용

AWS Transform for migrations now recommends the optimized storage type and configuration for every server you migrate, so you no longer do it server by server. Building on recent storage assessment capabilities, AWS Transform's recommendations use each server's observed performance and capacity data to reduce overprovisioning costs and avoid performance issues after cutover. You see the expected cost before you migrate, and AWS Transform applies the approved settings automatically at launch. 
Recommendations cover Amazon EBS and Amazon FSx for NetApp ONTAP. For FSx for NetApp ONTAP, they include the file system layout and sizing. You choose whether to optimize for cost or for performance, and recommendations stay consistent from assessment through launch. 
This capability is available in all AWS Regions where AWS Transform for migrations is available.  
To learn more, see the AWS Transform user guide.
