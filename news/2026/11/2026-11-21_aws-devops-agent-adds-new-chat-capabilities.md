# AWS DevOps Agent adds new chat capabilities

**날짜:** 2026년 11월 21일
**서비스:** General
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/11/devops-agent-new-chat-capabilities/

## 내용

AWS DevOps Agent now extends its chat capabilities across MCP clients like Kiro and Claude Code, as well as Slack and Microsoft Teams channels. With Model Context Protocol (MCP) support, AWS DevOps Agent can now take directed chat actions including support for GitHub, GitLab, Azure DevOps, ServiceNow, and PagerDuty MCP tools, giving developers and operations teams powerful workflow automation directly from their preferred chat interface.
This launch also adds auto-creation of per-incident Slack code channels and bi-directional chat within Microsoft Teams. AWS DevOps Agent has access to a compute sandbox that it can use to execute scripts and access the network to work more efficiently, and users can now rename and archive chats across all supported platforms.
See all the latest AWS DevOps Agent features on the release history page. For the list of AWS Regions where AWS DevOps Agent is available, see the supported Regions table.
