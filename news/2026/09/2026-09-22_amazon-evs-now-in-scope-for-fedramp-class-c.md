# Amazon EVS now in scope for FedRAMP Class C

**날짜:** 2026년 09월 22일
**서비스:** EC2
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/09/amazon-evs-fedramp-class-c/

## 내용

The&nbsp;Amazon Elastic VMware Service (EVS) service is now in scope for FedRAMP Class C (formerly Moderate baseline) in all United States Regions.&nbsp;
 
 
 The&nbsp;&nbsp;Federal Risk and Authorization Management Program&nbsp;(FedRAMP)&nbsp;is a US government-wide program that delivers a standard approach to the security assessment, authorization, and continuous monitoring for cloud products and services.&nbsp;Amazon EVS lets you run the latest VMware Cloud Foundation (VCF) software directly within your Amazon Virtual Private Cloud (VPC) on EC2 bare-metal instances. You can set up a complete VCF environment in just a few hours, enabling rapid workload migration to AWS to help you eliminate aging infrastructure, reduce operational risks, and meet critical timelines for exiting your data center.
 
 
 To learn more, visit the FedRAMP&nbsp;AWS services in scope page. To learn more about Amazon EVS, visit the&nbsp;product detail page and user guide.&nbsp;
