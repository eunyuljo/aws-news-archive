# AWS Billing Conductor now supports custom rates and usage tier pricing configurations

**날짜:** 2026년 09월 16일
**서비스:** Config
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/09/AWS-Billing-Conductor-custom-rates-usage-tier

## 내용

AWS Billing Conductor now lets you define custom rate pricing for AWS services, including defining custom usage tiers to configure rates by the desired usage volume.&nbsp; 
Customers and Partners using AWS Billing Conductor to model commercial agreements with subsidiaries, affiliates, or end customers can now more easily reflect their negotiated pricing on pro forma billing data. Using SKU-scoped pricing rules, you can enter a custom rate and configure usage tier thresholds — instead of marking up or down from the public on-demand rates tied to pre-defined AWS usage tiers.&nbsp; 
By configuring exact rates and tier breaks directly in a pricing rule, you no longer need to calculate percentage-based markups or markdowns against public on-demand pricing to model your commercial agreements. This gives you precise control over your pro forma billing configuration. 
Custom rates and custom usage tiers configuration via SKU-scoped pricing rules is available in all commercial AWS Regions, excluding the Amazon Web Services China (Beijing) Region, operated by Sinnet, and the Amazon Web Services China (Ningxia) Region, operated by NWCD.&nbsp;To learn more, visit the AWS Billing Conductor product page, or review the User Guide.
