# Amazon Quick now generates individual sheets and builds analyses from an image

**날짜:** 2026년 09월 18일
**서비스:** RDS
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/09/generate-sheet-and-generate-analysis-from-an-image/

## 내용

Amazon Quick now expands Generate Analysis with two new ways to create dashboards faster. You can generate a single sheet inside an existing analysis by describing it in natural language, and you can generate a new analysis from an image of an existing dashboard. 
&nbsp; 
With Generate Sheet, you describe the sheet you want and Amazon Quick adds it to your current analysis with visuals selected for your data, filter controls, and calculated fields such as year-over-year growth and month-over-month comparisons. You can extend an analysis without building each visual by hand. 
&nbsp; 
With generate an analysis from an image, you attach an image of a dashboard, including dashboards from other BI tools, to your prompt when you generate an analysis. Amazon Quick recreates it as an editable analysis, building what is supported in Amazon Quick. Both capabilities work with existing publishing workflows, embedding, CI/CD pipelines, and point-and-click editing. 
&nbsp; 
At launch, Generate Sheet and generate analysis from an image are available to Enterprise subscription/Author Pro users. Authors also have promotional access to this capability through December 2026 as part of Amazon Quick Enterprise, provided their organization has not restricted access. 
&nbsp; 
To learn more, see Generating an analysis with natural language prompts in the Amazon Quick User Guide. To get started, open an analysis and choose Generate Sheet, or attach an image to your prompt and choose Generate analysis.
