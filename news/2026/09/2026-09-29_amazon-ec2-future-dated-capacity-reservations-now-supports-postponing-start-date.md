# Amazon EC2 Future-dated Capacity Reservations Now Supports Postponing Start Dates

**날짜:** 2026년 09월 29일
**서비스:** EC2
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/09/ec2-fcr-postpone-start-date/

## 내용

Amazon EC2 Future-dated Capacity Reservations let you secure capacity up to 120 days in advance by specifying the capacity you need, the start date, and a commitment duration. If your plans change before delivery, you can now postpone your start date to match your new timeline.
When you postpone your start date, EC2 presents a quote that shows the new start date and the required commitment duration. The commitment duration can increase, depending on when you postpone the start date. After you review and accept the quote, EC2 updates your reservation with the new start date.
This feature is available to all Future-dated Capacity Reservation customers. Refer to the AWS Capabilities by Region website for the feature's regional availability. For more details, refer to the Capacity Reservation user guide.
