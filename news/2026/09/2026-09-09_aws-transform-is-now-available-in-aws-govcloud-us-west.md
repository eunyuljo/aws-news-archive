# AWS Transform is now available in AWS GovCloud (US-West)

**날짜:** 2026년 09월 09일
**서비스:** SystemsManager
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/09/aws-transform-govcloud-us-west/

## 내용

AWS Transform is now available in the AWS GovCloud (US-West) Region, enabling government agencies and regulated organizations to plan and execute large-scale migrations to AWS. With this launch, customers operating in AWS GovCloud (US) can use the migration capabilities of AWS Transform to automate server migrations within an isolated environment designed to host sensitive data and regulated workloads. AWS Transform in this Region supports migrating servers to both AWS GovCloud (US-East) and AWS GovCloud (US-West) as target Regions. 
Organizations migrating VMware, bare metal, Hyper-V, or database workloads can use AWS Transform to automate server replication and cutover, reducing the manual effort and risk involved in large-scale moves. This is particularly valuable for federal agencies, defense contractors, and regulated industries that must operate within the AWS GovCloud (US) boundary. Modernization, custom transformation, and assessment capabilities are not included in this regional launch and remain available in supported commercial Regions. 
To get started, see the AWS Transform documentation or visit the AWS Transform product page.
