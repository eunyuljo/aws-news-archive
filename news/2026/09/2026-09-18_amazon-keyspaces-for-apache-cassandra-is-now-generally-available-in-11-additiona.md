# Amazon Keyspaces (for Apache Cassandra) is now generally available in 11 additional Regions

**날짜:** 2026년 09월 18일
**서비스:** Keyspaces
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/09/amazon-keyspaces/

## 내용

Amazon Keyspaces (for Apache Cassandra) is now generally available in 11 additional Regions,&nbsp;allowing customers in those Regions to build Cassandra-compatible applications with lower latency while keeping their data within the Region to meet data residency requirements..&nbsp;  Amazon Keyspaces (for Apache Cassandra) is a scalable, highly available, and managed Apache Cassandra–compatible database service. Amazon Keyspaces is serverless, so you pay for only the resources that you use and you can build applications that serve thousands of requests per second with virtually unlimited throughput and storage.&nbsp;  To find the list of new available Regions, see the following resources: AWS Capabilities by Region.
