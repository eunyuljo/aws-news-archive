# Web Search now available on Kiro in AWS GovCloud (US)

**날짜:** 2026년 10월 31일
**서비스:** General
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/10/kiro-web-search-aws-govcloud-us/

## 내용

Kiro web search gives the agent real-time access to current information on the internet, so its answers draw on up-to-date search results and page content. The agent uses web search automatically when a question involves recent changes or topics beyond the model's training data. Answers that use web results include citations. 
Kiro enterprise administrators can turn off web search and web fetch for their organization from the Kiro console under Settings. Teams can also remove web tools from individual custom agents, or block them with capability-based permission rules. 
For more details, visit the&nbsp;AWS GovCloud (US) documentation, the monitoring and tracking guide, or contact your AWS account team. To learn more about Kiro, visit the Kiro product page.
