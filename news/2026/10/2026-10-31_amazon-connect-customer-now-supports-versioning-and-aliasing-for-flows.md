# Amazon Connect Customer now supports versioning and aliasing for flows

**날짜:** 2026년 10월 31일
**서비스:** EBS
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/10/connect-flows-versioning-aliasing/

## 내용

Amazon Connect Customer now supports versioning and aliasing for flows and flow modules, simplifying how you build, test, and deploy customer experience flows while minimizing impact to live end-customer traffic. With this launch, you can now create immutable versions of a flow and attach one or more friendly names (i.e., aliases) to a version, then point resources such as queues, quick connects, and phone numbers at an alias instead of a specific version. 
Rolling out a new version takes a single update, with no need to republish or relink each resource. For example, you can publish an updated customer experience flow as a new version and validate it in a test environment while live traffic stays on the current version, then repoint the production alias to move every phone number to the new version in a single update. 
This feature is available in all AWS Regions where Amazon Connect Customer is offered. To learn more, see Flow versioning and aliasing in the Amazon Connect Customer Administrator Guide. To learn more about Amazon Connect Customer, an agentic AI solution that helps enterprises deliver exceptional customer experiences, visit the Amazon Connect Customer website.
