# Second-generation AWS Outposts racks now supported in the AWS Mexico (Central) Region

**날짜:** 2026년 10월 17일
**서비스:** Connect
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/10/aws-outposts-racks-mexico-central/

## 내용

Second-generation AWS Outposts racks are now supported in the AWS Mexico (Central) Region. Outposts racks extend AWS infrastructure, AWS services, APIs, and tools to virtually any on-premises data center or colocation space for a truly consistent hybrid experience.&nbsp;
 
 &nbsp;
 
 Organizations of every size, from startups to enterprises to public sector agencies, can now order Outposts racks connected to this newly supported Region to optimize for latency and data residency needs. This regional expansion provides additional flexibility in the number of AWS Regions that customers’ Outposts can connect to.
To learn more about second-generation Outposts racks, read the&nbsp;blog post and the&nbsp;user guide. For the latest list of countries and territories and the AWS Regions where second-generation Outposts racks are supported, see the Outposts rack FAQs page.
