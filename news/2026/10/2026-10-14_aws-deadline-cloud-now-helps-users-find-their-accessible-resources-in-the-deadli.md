# AWS Deadline Cloud now helps users find their accessible resources in the Deadline Cloud monitor

**날짜:** 2026년 10월 14일
**서비스:** General
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/10/deadline-cloud/resources

## 내용

AWS Deadline Cloud now lets users who have access to specific queues, fleets, or jobs, rather than an entire farm, find the resources they can reach directly from the Deadline Cloud monitor. Deadline Cloud is a fully managed service that helps teams run compute-intensive workloads for visual effects, animation, product design, simulation, and gaming.
Previously, a user with access to only one queue had to get the farm ID from an administrator before they could reach their work. With this launch, the Deadline Cloud monitor displays to users queues they have access to, the parent IDs needed to reach them, and their level of access, covering both direct and group-inherited permissions. Teams now can share a single monitor entry point (URL) across different permission levels without additional coordination.
Resource discovery is available in all AWS Regions where Deadline Cloud is available. To learn more, visit the AWS Deadline Cloud user guide.
