# AWS End User Messaging adds registration improvements for faster, higher-quality submissions

**날짜:** 2026년 10월 17일
**서비스:** General
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/10/aws-end-user-messaging-adds-registration-improvements-for-faster-higher-quality-submissions

## 내용

AWS End User Messaging now makes it easier to complete messaging registrations correctly the first time, with clearer guidance, explicit field requirements, and help avoiding the most common rejection reasons. Registrations ask for compliance evidence such as opt-in proof and sample messages, and submissions are often delayed or denied when that evidence is incomplete or a required field is missed. These improvements give you worked examples, surface exactly which fields you must provide, and walk you through the content that most often causes denials.
 
 
 First, example mock-ups of a compliant opt-in and sample messages are now included for US 10DLC, US short code, US toll-free and RCS registrations, so you can see what a compliant submission looks like before you build your own. Second, the registration API response now surfaces conditional logic, so you and your AI agents no longer have to guess which fields are required based on other field values. The response tells you which fields are required for your specific registration. Third, RCS registration now includes a walkthrough for recording the compliant video that agent registrations require.
 
 
 These improvements are available in all Regions where AWS End User Messaging registrations are available.
 
 
 To learn more and get started, see the End User Messaging User Guide.
