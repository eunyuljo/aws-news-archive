# AWS Security Hub now supports resource criticality for prioritization

**날짜:** 2026년 10월 14일
**서비스:** RDS
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/10/security-hub-resource-criticality/

## 내용

Today, AWS Security Hub adds resource criticality to exposure prioritization, helping central security teams focus on the exposures that threaten their most business-critical resources.
You can set criticality with an automation rule, for example marking every compute resource in a specific account as Very High. The rule applies to resources already in your inventory and to new resources as Security Hub discovers them. Security Hub also infers criticality from resource tags and resource names, with no configuration required, and records which source determined the value. Criticality appears as a column on the Resources page for sorting, filtering, and grouping, and on the Impact assessment tab of an exposure finding. Resource criticality is included with Security Hub Essentials at no additional cost and is always on for all customers.
