# AWS Transform for migrations is now available in Asia Pacific (Singapore)

**날짜:** 2026년 10월 17일
**서비스:** General
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/10/aws-transform-singapore

## 내용

AWS Transform for migrations is now available in the Asia Pacific (Singapore) Region, giving customers data residency within the region and lower latency to local source infrastructure as they migrate. AWS Transform is a collaborative enterprise IT transformation service powered by agentic AI that accelerates cloud migration, application modernization, and continuous tech debt reduction.
 
 
 With AWS Transform for migrations, enterprise IT teams can automate the entire migration lifecycle, from discovery and wave planning through network conversion and launching test and cutover instances, using purpose-built AI agents. The service supports infrastructure migration for workloads from virtually any source, including VMware, Hyper-V, KVM, bare metal, and hybrid environments, unifying teams, tools, and workflows in a single collaborative workbench.
 
 
 To get started, see the AWS Transform documentation or visit the AWS Transform product page.
