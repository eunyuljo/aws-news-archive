# Amazon Connect Customer Global Resiliency now provides business users visibility into resiliency readiness across linked Regions

**날짜:** 2026년 10월 20일
**서비스:** EBS
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/10/amazon-connect-global-resiliency-readiness-overview

## 내용

Amazon Connect Customer Global Resiliency now provides a Global Resiliency page in the admin website, giving administrators a single place to review their Region switch readiness. The page shows an overall readiness status and lists the resources that Global Resiliency natively replicates, including which resource types are in sync, which are still pending synchronization, and which need action. For example, if a phone number or user is not associated with a traffic distribution group, the page flags it and lets the administrator associate the affected resources directly from the page. With this readiness overview, administrators can review their resiliency posture at any time and verify that their instance is ready for a Region switch.
This feature is available in all AWS Regions where Amazon Connect Customer Global Resiliency is supported. To learn more, see Amazon Connect Customer admin guide.
