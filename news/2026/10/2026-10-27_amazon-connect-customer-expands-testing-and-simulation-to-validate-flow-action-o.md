# Amazon Connect Customer expands testing and simulation to validate flow action outcomes

**날짜:** 2026년 10월 27일
**서비스:** Lambda
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/10/connect-customer-validate-flow-actions/

## 내용

Amazon Connect Customer now enables you to validate the outcomes of your customer experience flow actions during testing and simulation. In addition to confirming that an action started, you can now verify the data it returns when it completes, such as a Lambda function response, an Amazon Lex resolved intent, or the variables set by an Agentic CX block. When a test fails, you can pinpoint the exact action that returned an unexpected result instead of tracing it back from a downstream step, so you can resolve issues faster and launch flow changes with greater confidence. 
To learn more about this feature, see testing and simulation in the Connect Customer administrator guide. For a complete list of testing and simulation capabilities available by AWS Region, refer to Availability of Connect Customer features by Region. To learn more about Amazon Connect Customer, an agentic AI solution that helps enterprises deliver exceptional customer experiences, visit the Amazon Connect Customer website.
