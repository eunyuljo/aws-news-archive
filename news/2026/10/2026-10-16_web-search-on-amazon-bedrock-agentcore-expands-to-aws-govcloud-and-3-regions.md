# Web Search on Amazon Bedrock AgentCore expands to AWS GovCloud and 3 Regions

**날짜:** 2026년 10월 16일
**서비스:** Bedrock
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/10/amazon-bedrock-agentcore/

## 내용

Web Search on Amazon Bedrock AgentCore is now available in four additional AWS Regions: US East (Ohio), US West (Oregon), Asia Pacific (Sydney), and AWS GovCloud (US-West). Web Search is a fully managed tool that provides AI agents with current grounding from the web, enabling more accurate and up-to-date responses for tasks such as research, summarization, and question answering.
With this expansion, customers can build agents that retrieve web information closer to their applications and end users with lower latency. Customers with government workloads can now use Web Search in the AWS GovCloud (US-West) Region to meet compliance and data residency requirements.&nbsp;
To learn more about Web Search on Amazon Bedrock AgentCore, see the Web Search tool documentation. To learn about pricing, visit Amazon Bedrock AgentCore pricing. For Region availability, visit Supported AWS Regions.
