# AWS Transfer Family console supports SVG logos and ICO favicons for web apps

**날짜:** 2026년 10월 15일
**서비스:** TransferFamily
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/10/transfer-family-svg-ico-favicons/

## 내용

The AWS Transfer Family console now supports SVG files for logos and ICO files for favicons in web apps, with upload limits increased to 2 MB. This gives you more flexibility to use existing branding assets when customizing your web app.
Previously, the console accepted only JPG and PNG files and limited logo uploads to 50 KB and favicon uploads to 20 KB. The console automatically resizes images and converts them to JPG or PNG before saving them. Existing API upload limits and format requirements remain unchanged.
These capabilities are available in all AWS Regions where Transfer Family web apps are offered. To learn more, see the Transfer Family web apps tutorial.
