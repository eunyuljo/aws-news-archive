# AWS Deadline Cloud now supports ECS containers on Linux Service-Managed Fleets

**날짜:** 2026년 10월 01일
**서비스:** ECS
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/08/aws-deadline-cloud-ecs-containers-linux-smf/

## 내용

AWS Deadline Cloud now supports running jobs using Docker containers from Amazon Elastic Container Service (ECS) on Linux-based service-managed fleets. Deadline Cloud is a fully managed service that helps teams run compute-intensive workloads in the cloud for visual effects, animation, product design, simulation, and gaming.
 
 
 Deadline Cloud customers can now bring their own software containers directly to the service using Docker-enabled fleets. Customers that already package software into container images can point Deadline Cloud to these images directly. This unlocks any container-deployed software use case, from rendering tools like Blender to physical AI workloads such as NVIDIA Isaac Sim and MuJoCo. With service-managed fleets, Deadline Cloud automatically deploys the containerized software on every worker instance at scale.
Containers are integrated with Deadline Cloud fleets and queues, so that customer job templates do not need to contain container commands or image references. This means the same job bundles customers run locally with the Open Job Description CLI can be submitted to Deadline Cloud with no additional changes. The result is a faster path from existing containerized software workflows to a fully managed render and compute farm.
Container support for service-managed fleets is available in all AWS Regions where Deadline Cloud is offered.
To get started, see our user guide and our developer guide.
