# AWS Elemental MediaConnect Router now supports high bitrate mode

**날짜:** 2026년 10월 20일
**서비스:** Connect
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/10/mediaconnect-router-high-bitrate/

## 내용

AWS Elemental MediaConnect Router now supports high bitrate modes with two new tiers: 250 Mbps and 500 Mbps. This allows professional broadcasters that need higher bitrates to transport high-value content without compromising quality or reliability.
This enhancement enables industry-standard workflows such as VSF TR-07 compliant transport stream distribution for broadcast contribution, content distribution, and remote production. High bitrate mode supports up to two redundant sources for reliability and includes data plane optimizations that reduce jitter for improved performance.
To learn more, visit the AWS Elemental MediaConnect product page and the MediaConnect pricing page.
