# Amazon MWAA now available in Mexico (Central) Region

**날짜:** 2026년 10월 24일
**서비스:** CloudFormation
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/10/amazon-mwaa-mexico-central/

## 내용

Amazon Managed Workflows for Apache Airflow (Amazon MWAA) Provisioned environments are now available in the Mexico (Central) Region (mx-central-1). Amazon MWAA Serverless was already available in this Region, and customers can now also use Amazon MWAA Provisioned environments for their Apache Airflow workflows. Amazon MWAA is a managed orchestration service for Apache Airflow that makes it easier for customers to set up and operate end-to-end data pipelines in the cloud at scale.
Customers can create Amazon MWAA Provisioned environments using the AWS Management Console, the AWS CLI, the AWS SDKs, or AWS CloudFormation. Customers in Mexico (Central) can now run their Amazon MWAA Provisioned workflows closer to their data sources and end users, reducing latency and helping meet data residency requirements. To learn more, visit the Amazon MWAA product page and the Amazon MWAA supported Regions documentation.
