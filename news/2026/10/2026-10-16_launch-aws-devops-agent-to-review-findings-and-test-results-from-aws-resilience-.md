# Launch AWS DevOps Agent to review findings and test results from AWS Resilience Hub

**날짜:** 2026년 10월 16일
**서비스:** Config
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/10/aws-devops-agent-test-results-aws-resilience-hub/

## 내용

The next generation of AWS Resilience Hub now integrates with AWS DevOps agent allowing you to review failure mode assessment findings and implement mitigations to resolve findings and review resilience test results. AWS Resilience Hub is a central location in the AWS Management Console that helps platform engineering and site reliability teams assess and strengthen the resilience of their workloads running on AWS. It provides automated dependency discovery, generative AI-powered failure mode analysis, modular resilience policies, resilience testing, and organization-wide resilience posture reporting.
Resilience test investigations: When you run a resilience test, Resilience Hub now launches an AWS DevOps Agent investigation that observes the test and returns a structured analysis. You can uncover symptoms, root cause, and impact along with observed recovery actions, like ARC Region switch.
Interactive agent analysis from failure mode assessment findings: You can now start AWS DevOps Agent on demand task directly from a failure mode assessment finding in the Resilience Hub console, with the finding's context already in place. This allows for asking questions and investigating findings to create a mitigation plan.
To get started, visit the AWS Resilience Hub console, select a service and configure DevOps agent in the service configuration. Then launch the DevOps agent directly from a failure mode assessment finding or a resilience test. To learn more, see the product page or visit the documentation.
AWS Resilience Hub is available in the following AWS Regions: US East (N. Virginia), US East (Ohio), US West (Oregon), Canada (Central), Europe (Ireland), Europe (London), Europe (Frankfurt), Europe (Paris), Europe (Stockholm), Asia Pacific (Mumbai), Asia Pacific (Singapore), Asia Pacific (Sydney), Asia Pacific (Tokyo), Asia Pacific (Seoul), and South America (São Paulo).
