# AWS Agent Registry is now available in four additional AWS Regions

**날짜:** 2026년 10월 30일
**서비스:** Bedrock
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/10/aws-agent-registry-four-regions/

## 내용

AWS Agent Registry, available through Amazon Bedrock AgentCore, is now available in four additional AWS Regions: Europe (London) eu-west-2, Europe (Frankfurt) eu-central-1, US East (Ohio) us-east-2, and Canada (Central) ca-central-1.
AWS Agent Registry is a fully managed discovery service that provides a centralized catalog for organizing, curating, and discovering resources across your organization. With AWS Agent Registry, you can publish MCP servers, tools, agents, agent skills, and custom resources into a searchable registry, control access through an approval workflow, and enable both human users and AI agents to discover the right tools and agents through hybrid search, catalog browsing, and a native MCP endpoint.
AWS Agent Registry is now available in nine AWS Regions. For a complete list of Region availability, see the AWS Regional Services List.
To get started, see the AWS Agent Registry documentation: https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/registry.html
