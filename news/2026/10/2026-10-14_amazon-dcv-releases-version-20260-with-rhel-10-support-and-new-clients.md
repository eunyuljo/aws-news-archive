# Amazon DCV releases version 2026.0 with RHEL 10 support and new clients

**날짜:** 2026년 10월 14일
**서비스:** EC2
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/10/amazon-dcv-2026-0/

## 내용

Amazon DCV 2026.0 is now available, adding support for RHEL 10, Rocky Linux 10, CentOS 10, and Ubuntu 26.04 along with a new macOS client and updated Windows and Linux clients. Amazon DCV is a high-performance remote display protocol that enables customers to securely access remote desktops and application sessions across Windows, Linux, and macOS.
Amazon DCV 2026.0 includes the following key features and improvements:

 
  Support for RHEL 10, Rocky Linux 10, CentOS 10, and Ubuntu 26.04, with Linux hosts and sessions running on the modern Wayland display server
 
 
  A new macOS client with gamepad support, and updated Windows and Linux clients
 
 
  URL redirection on Windows hosts, so configured links opened in a remote session launch in the local browser on the client device
 
 
  Printer preferences redirection on Windows, giving remote sessions access to client-side printer settings
 
 
  Performance improvements, including H.264 frame slice support and slice-based multithreaded decoding on the Linux and macOS clients for lower latency
 
 
  Support for new macOS server versions on Amazon EC2
 

For more information about the new features and enhancements in Amazon DCV 2026.0, see the release notes or visit the Amazon DCV webpage to learn more and get started.
