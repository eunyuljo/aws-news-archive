# Amazon S3 server access log delivery to Amazon CloudWatch Logs now available in five additional AWS Regions

**날짜:** 2026년 10월 22일
**서비스:** S3
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/10/amazon-s3-server-access-logs-cloudwatch-logs-regions/

## 내용

Amazon S3 server access log delivery to Amazon CloudWatch Logs is now available in the AWS GovCloud (US) Regions, AWS European Sovereign Cloud, and AWS China Regions. With your access logs in CloudWatch Logs, you can query them as they arrive, set alarms, and encrypt them with AWS Key Management Service (AWS KMS) keys. This new delivery path complements the existing delivery of server access logs to S3 general purpose buckets, giving you more flexibility in how you monitor and analyze access to your data. 
With delivery to CloudWatch Logs, you can set alarms on error rates, monitor traffic patterns, investigate access incidents, and correlate S3 access activity with the rest of your operational data. 
S3 server access log delivery to CloudWatch Logs is now available in all AWS Regions. Amazon CloudWatch Logs charges for vended logs apply. For pricing details, visit Amazon CloudWatch pricing. To learn more, visit the Amazon S3 User Guide.
