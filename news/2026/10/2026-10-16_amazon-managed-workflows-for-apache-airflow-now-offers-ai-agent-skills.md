# Amazon Managed Workflows for Apache Airflow now offers AI agent skills

**날짜:** 2026년 10월 16일
**서비스:** Config
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/10/amazon-mwaa-ai-agent-skills/

## 내용

Amazon Managed Workflows for Apache Airflow (MWAA) now integrates with the Agent Toolkit for AWS to provide built-in AI agent skills that let you author, debug, and test MWAA workflows and upgrade MWAA environments using any AI coding assistant that supports agent skills.
The four skills are authoring-mwaa-workflow, debugging-mwaa-workflow, testing-mwaa-workflow, and upgrading-mwaa-environments. Together they let your AI assistant interact directly with MWAA using natural language, reducing the manual effort of building and maintaining data pipelines. For example, you can describe an ETL pipeline in plain language and the authoring skill generates a working DAG complete with task dependencies and error handling.
The Amazon MWAA AI agent skills work with both Amazon MWAA Provisioned and Amazon MWAA Serverless environments, and are available in all AWS Regions where Amazon MWAA is available.
To get started, install the aws-data-analytics plugin and configure your AI coding assistant to use the MWAA agent skills. To learn more, see Using agent skills with Amazon MWAA in the Amazon MWAA User Guide and the Agent Toolkit for AWS documentation.
