# Amazon Connect Customer Global Resiliency now supports persistent chat across linked AWS Regions

**날짜:** 2026년 10월 24일
**서비스:** Connect
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/10/amazon-connect-global-resiliency-persistent-chat

## 내용

Amazon Connect Customer Global Resiliency now provides customers a mechanism to deliver long, persistent chat experiences across linked AWS Regions. With this capability, end users can resume previous conversations with full context, metadata, and transcripts carried over across Regions, eliminating the need for end users to repeat information and allowing agents to provide personalized service with access to the entire conversation history across AWS Regions. 
For example, an end user can start a chat in US-East (N. Virginia) and later come back to it in the linked US-West (Oregon) Region, continuing the same conversation with an agent with full conversation history&nbsp;and&nbsp;chat attachment. To adopt this capability, onboard to Global routing. 
This feature is available in all AWS Regions where Amazon Connect Customer Global Resiliency is supported. To learn more, visit Amazon Connect Customer Admin Guide.
