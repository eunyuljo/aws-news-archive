# Amazon S3 is now available on the Vercel Marketplace and v0 by Vercel

**날짜:** 2026년 10월 15일
**서비스:** S3
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/10/amazon-s3-vercel-marketplace-v0

## 내용

Amazon S3, including S3 Tables and S3 Vectors, is now available on the Vercel Marketplace and v0 by Vercel. Developers can create and connect S3 resources in seconds without leaving their development environment, getting the durability, scalability, and performance of S3 through Vercel's streamlined provisioning workflow.
Millions of customers rely on S3 for low-cost, high-performance storage to power web and AI applications, but until now provisioning it from Vercel required navigating to the AWS Management Console. Now, S3 integrates directly into the Vercel developer experience, automatically handling resource provisioning and connection configuration. You can choose from S3 general purpose buckets for virtually any use case, S3 Tables for fully managed Apache Iceberg tables optimized for analytics workloads, or S3 Vectors to natively store and query vectors at scale.
New AWS accounts created through Vercel include $100 in credits valid for up to six months, usable across Amazon S3, Amazon OpenSearch Serverless, and AWS Database services. Existing AWS customers can link their account to use S3 with their Vercel projects.
Amazon S3 on Vercel is now available in all AWS Regions where Vercel is available. To get started, read the AWS News Blog, visit AWS on Vercel Marketplace, or launch v0 by Vercel.
