# AWS CodeBuild now supports Amazon Linux 2023 for on-demand build hosts

**날짜:** 2026년 07월 09일
**서비스:** CodeBuild
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/07/aws-codebuild-amazon-linux-2023/

## 내용

AWS CodeBuild now supports Amazon Linux 2023 for on-demand build hosts through a new host kernel selection setting. AWS CodeBuild is a fully managed continuous integration service that compiles source code, runs tests, and produces software packages that are ready to deploy. With this launch you can choose whether your build host uses Amazon Linux 2 (Linux kernel 4) or Amazon Linux 2023 (Linux kernel 6).&nbsp; 
Amazon Linux 2023 offers several improvements over Amazon Linux 2, including an updated Linux kernel and glibc, along with package additions, upgrades, and removals. For a full comparison, see Comparing AL2 and Amazon Linux 2023.&nbsp; You can validate Amazon Linux 2023 at your own pace by setting the host kernel on a new or non-production project and running your builds there, while your production projects keep running unchanged on their current kernel. 
Host kernel selection is available in all AWS Regions where CodeBuild is offered except the AWS GovCloud (US) and China Regions, which only support Amazon Linux 2023.
