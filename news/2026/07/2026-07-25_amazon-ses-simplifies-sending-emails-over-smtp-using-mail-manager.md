# Amazon SES simplifies sending emails over SMTP using Mail Manager

**날짜:** 2026년 07월 25일
**서비스:** Config
**링크:** https://aws.amazon.com/about-aws/whats-new/2026/07/amazon-ses-simplified-smtp-mail-manager

## 내용

Amazon Simple Email Service (SES) now offers a simplified console experience for sending emails over SMTP using Mail Manager. Mail Manager is a capability within SES for managing email flow, but configuring its resources individually to set up SMTP sending requires multiple steps. The new guided setup creates and configures these resources automatically, so developers can get started in just a few clicks. 
The guided setup gives developers a working SMTP endpoint and downloadable credentials they can plug into any application or framework that supports SMTP. This is ideal for teams building applications that send email notifications, password resets, or transactional messages and need a fast path to a production-ready SMTP configuration. 
This experience is available in all AWS Regions where Amazon SES is available. 
To learn more, visit the Amazon SES console or refer to the documentation.
